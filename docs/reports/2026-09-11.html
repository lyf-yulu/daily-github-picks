3Dviz Pro Max 是一款面向创意型 3D 可视化的独立 Agent 技能包，可作为 Claude Code 插件或 Codex 技能目录直接接入，帮助 AI 助手将一句自然语言描述转化为可以真正打开探索的 Three.js/Blender 场景。项目围绕一个十步工作流展开：塑造世界、建立规则、加入交互、并对渲染帧进行截图回读，让智能体基于实际画面而非文字描述来迭代，避免出现「用动画糊弄成仿真」的问题。仓库当前收录 223 条食谱（recipes）、440 条知识记录（其中 69 条带作者标注的数值默认值）、22 个经过 SHA-256 校验四帧真图的 Kit 蓝图、37 个风格档案和 37 个可运行示例研究，覆盖环境、角色与运动、产品装配、建筑室内、物流运营、解剖学、生理生物力学、分子材料、立体几何、线性代数、微积分与场、概率统计等 24 个方向，共计 451 个来源、3599 条证据事件构成公开证据档案。技术层面基于 Three.js 0.180 与 Blender 烘焙管线，配套 headless Chromium 于 1920×1080 GPU 环境下产出 21 张展示帧。落地页会在构建期从 skills/、docs/、evals/、evidence/ 目录重新计算所有数字，从机制上杜绝文档与真实数据漂移。事实类解释必须附来源，装饰性动画则明确区分，不冒充仿真。
在「AI 生成 3D」赛道上，多数方案止步于 prompt 到几何体，本项目把创意 3D 的整个生产流程沉淀成可检索的技能包：既有可运行的 Three.js/Blender 模板，又用截帧回读把智能体从「口述场景」拉回「看图迭代」，同时用 SHA-256、证据事件、构建期重算等工程手段保证目录数字与实物一致。对希望把 Claude Code / Codex 用于严肃视觉化工作、而非玩具 Demo 的开发者，具备很强的参考价值。

Bang Motion 动态图形技能包 ⭐ 131

让 AI 生成真正会动的浏览器动画

Agent Skills 规范HTML/CSS/JavaScriptGSAP 动画库WebGLPuppeteer（可选，帧截图/导出）FFmpeg（可选，MP4 导出）Node.js
Bang Motion 是一个面向 AI 编程代理（Claude Code、Codex、Gemini CLI、Cursor 等）的 Agent Skill 插件，专门用于在浏览器中生成高质量的动态图形作品，包括产品开场、宣传片、频道 ID、动感字体、下三分之一字幕以及五种解说风格的短片。项目最终交付物是一个可以双击直接播放的 index.html 文件，自带自动播放和循环，无需 npm install 即可观看。它的核心理念是解决 AI 生成动画时常见的『幻灯片化』问题——把一段视频拆成一节一节淡入淡出的段落，而是通过一套结构化规则强制代理生成连续世界、持久主体和真实运镜的动画。项目提供风格简报机制，强制从菜单中挑选调色板、显示字体、背景表面、背景运动、转场和运动签名，并禁止跨项目重复使用同一选项，从根源上避免 AI 抄用默认套路。它内置五种解说模板（卡通拼贴、视觉新闻、白色目录、复古手绘、连续动作矢量），提供确定性时间线（每一帧都是时间的纯函数），支持配音脚本回填与自动重定时，还能通过 puppeteer 与 ffmpeg 完成逐帧导出为 MP4。技术上基于 GSAP 动画库、原生 HTML/CSS/JS 与可选的 WebGL，通过 CDN 加载依赖，实现零安装即可运行。
这是一个非常独特的 Prompt 工程范例：它没有训练新模型，而是通过一套精心设计的『风格简报 + 菜单选择 + 结构自检』规则，把资深动态设计师的隐性经验形式化为 AI 代理能够验证的检查项。相比多数只教 AI『写代码』的技能包，Bang Motion 教 AI『避免审美惰性』，直击当前 LLM 生成视觉内容时最难解决的『平庸默认值』问题。同时它跨代理（Claude Code、Codex、Gemini、Cursor）通用，交付物是零依赖的单个 HTML，工程完成度和产品思路都值得动画创作者与 AI 工具作者研究。

pcb-skill 是一个面向硬件开发的 Agent 技能包，运行于 Claude Code 或 Codex 桌面端，通过 MCP 协议驱动嘉立创 EasyEDA Pro，把一个硬件想法完整推进到可下单、可焊接、可点亮的 PCB。工作流分为四个阶段：概念确认、原理图与元器件采购、布局布线、制造与购买，每个阶段都有明确的验收门槛。项目秉持三条原则：性价比（价格必须来自实时页面或明确标注为估算）、好装配（禁用底部端子封装、保证手工可焊顺序）、免费 PCB（从第一笔设计就落在打样免费尺寸内）。技术亮点包括：独立于 EDA 的 Gerber 解析与净表断言校验、Specctra DSN/SES 自动布线链、四态看门狗、基于真实焊盘的 courtyard 计算，以及浏览器端将购物车推进到付款前页面（下单与付款始终由人工完成）。仓库通过一个真实案例沉淀出四条铁律：绿板不等于正确板、测量优于推断、先验证工具再验证结果、等待条件必须能在崩溃时输出日志。

Crypto-RAG 印尼语加密资产助手 ⭐ 898

RAG 知识库融合实时行情的加密助手

PythonFAISSfastembedBM25websocket-clientOpenAI 兼容 LLM APICoinGecko APIBinance / OKX / Bybit / KuCoin / Kraken / Coinbase APIDefiLlama APIMempool.space API
crypto-rag 是一个面向印尼语用户的加密货币智能问答助手，核心理念是将 RAG（检索增强生成）与实时市场数据严格分离：静态的概念、教育、协议描述放入向量库，而价格、资金费率、TVL 等易变数值一律通过 tool-call 在查询时实时抓取，避免 LLM 对数字产生幻觉。项目内置一个意图路由器，会根据用户问题分发到不同的数据源：概念类走 FAISS 知识语料（146+ 印尼语主题），价格类调用 Binance、OKX、Bybit、KuCoin、Kraken、Coinbase 六大交易所并对比套利空间，衍生品数据取自 Binance Futures，TVL 与 DEX 数据来自 DefiLlama，情绪数据取 Fear & Greed Index，另外还接入了 Mempool.space、以太坊 EIP-1559 gas、Solana 供应与通胀等链上指标。检索层采用 BM25 + dense embedding（fastembed）经 RRF 融合的混合检索，可选 cross-encoder 重排。用户体验方面提供交互式聊天（带追问记忆）、WebSocket 亚秒级行情、多币种 watch 模式与条件告警（如 BTC>65000）、投资组合追踪、LLM token 流式输出，以及一个 tool-calling agent 用于自动编排多步复杂查询（如跨币种资金费率对比）。LLM 层兼容 OpenAI 协议，支持 StepFun、Groq、Ollama、LM Studio 等，未配置时自动回退到抽取式回答，并保留引用与免责声明。
该项目呈现了一种 crypto 场景下相当克制且正确的 RAG 设计范式：拒绝把易变数字塞进向量库，将 LLM 定位为语义合成器而非数据源。这种「静态走 RAG、动态走 tool-call、数字不过 LLM」的分层不仅规避了金融领域最致命的幻觉风险，也让整套系统在没有 API key 的前提下即可运行，同时兼顾意图路由、混合检索、agent 编排与流式体验，对做垂直领域 RAG 的开发者是相当值得参考的工程样本。
