Bang Motion 浏览器动效技能包 ⭐ 108

让 AI 代理生成真正会动的网页动画

HTML5GSAPWebGLJavaScriptAgent Skills (SKILL.md)Claude Code PluginNode.jsPuppeteerffmpeg
Bang Motion 是一个面向 AI 编码代理（Claude Code、Codex、Gemini CLI、Cursor 等）的 Agent Skill 技能包，用于在浏览器中生成专业级动态图形作品，涵盖产品开场片、宣传片、频道包装、动态字幕、下三分之一字幕以及五种解说风格。最终交付物只有一个 index.html 文件，双击即可播放，自动循环且无播放器边框，无需 npm install。项目的核心痛点在于：让 AI 直接生成视频时，往往得到的是幻灯片式产物（一段一图一标题加淡入淡出），而 Bang Motion 把资深动效设计师的经验编码为代理可在自身代码中校验的结构性规则，例如统一的世界观、真正移动的镜头、贯穿全片的主角、嵌入场景内的数字等。它通过强制的风格简报（基于品牌调色板、显示字体、背景表面、背景运动、转场、动效签名等菜单选项，且要求与上个项目不同）来避免风格重复，并提供五种解说风格起手模板：卡通拼贴、视觉新闻、白底目录、复古手绘、连续动作矢量。技术上基于 GSAP 动画库（CDN 加载）、确定性时间线（帧是时间的纯函数）、可选 Puppeteer + ffmpeg 用于帧导出与 MP4 生成，并支持配音工作流（脚本回填音频后自动重新配时）。
它抓住了 AI 生成动画作品最普遍的失败模式——退化为幻灯片，并给出一套可被代理机器校验的反幻灯片规则体系，而不是单纯的 prompt 技巧。这种把设计师隐性知识转化为结构化约束和菜单选择的做法，对 Agent Skills 生态和 AI 生成创意内容的可控性都具有借鉴价值。

Penelopa.ai ⭐ 91

为 AI 编码代理持续改进的伴侣

Node.jsElectronTypeScriptPlaywrightShell/PowerShell 安装脚本Web Dashboard
Penelopa.ai 是一款面向 AI 编码代理（Codex 与 Claude Code）的持续改进工具。它通过在本地安装 Hook，捕获真实的编码会话事件，分析开发者与 AI 代理协作过程中反复出现的工作流模式，并将其转化为可复用的技能、检查项、提示词和优化建议，最终在个人 Web 仪表盘或桌面伴侣应用中呈现。项目提供 macOS、Windows、Linux 一键安装脚本，自带私有 Node/npm 运行时，无需依赖 Git、Python、Homebrew 或系统 npm。桌面端基于 Electron 构建，凭据通过 safeStorage/Keychain/DPAPI 保护，Web 端与 CI 使用 Playwright 与 Chromium 进行单元、视觉与端到端测试。安装器还支持诊断、修复、卸载、暂停采集等运维操作，Hook 事件通过后台 worker 队列可靠上传，失败会持久化重试，保障采集链路稳定。

该项目是一个面向 AI 编程代理（Agent）的性能优化系统，目标是为 Claude Code、Codex、Opencode、Cursor 等主流 AI 编码助手提供统一的能力增强层。项目围绕五大核心维度构建：Skills（技能库，封装可复用的开发能力）、Instincts（直觉，让代理在决策时具备类人的判断偏好）、Memory（记忆机制，跨会话保持上下文与经验）、Security（安全防护，规避危险操作与敏感信息泄漏）以及 Research-first Development（研究先行的开发范式，鼓励代理在动手前先调研代码库与文档）。通过这套 harness，开发者可以显著提升 AI 代理在真实项目中的可靠性、准确度与协作效率，避免常见的幻觉与鲁莽操作。项目定位为跨平台的代理增强中间层，不绑定单一 AI 提供商，可作为通用 prompt/工具调用规范复用到不同代理运行时中。由于 README 内容较为精简，项目更像是一份方法论与规范集合，通过标准化的技能定义、记忆存储格式与安全护栏，形成可移植的代理最佳实践。适用于希望将 AI 编码助手引入严肃工程环境的团队，也适合研究代理架构演进方向的开发者参考。
在 AI 编码代理迅速普及的当下，如何让这些代理在真实工程中表现稳定、安全、可控是行业共同难题。该项目跳出单一工具视角，抽象出一套可复用于多种代理的性能优化范式，把 Skills、Memory、Security 等常被忽视的关键要素显式化，具有明显的方法论价值。对于想要构建企业级 AI 编码工作流或研究代理架构的团队，这类跨平台的 harness 系统是很值得跟踪的方向。
