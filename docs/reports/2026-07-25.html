Agent Council 智能体议会 ⭐ 94

多AI CLI协作会诊插件

Node.jsBash ShellYAMLClaude Code SkillCodex CLIGemini CLI
Agent Council 是一款面向 Claude Code 的多智能体协作技能插件，灵感来自 Karpathy 的 LLM Council。它通过调用用户本地已安装的 AI CLI 工具（如 Claude Code、Codex CLI、Gemini CLI 等）并行收集多方观点，再由一位可配置的主席（Chairman）综合各方意见给出最终建议，帮助开发者从多元视角审视问题。与直接调用各家 LLM API 的方案不同，本项目复用已有 CLI 订阅，不产生额外 API 费用。工作流程分为三阶段：并行分发问题、收集展示各智能体回复、由宿主智能体或指定 CLI 作为主席进行综合。项目支持通过 npx 安装或 Claude Code 插件市场安装，自动识别 .claude/ 与 .codex/ 目录，并通过 council.config.yaml 灵活配置成员、命令、图标与颜色。核心执行由 council.sh 脚本驱动，支持 start/status/results/clean 及一次性 wait 模式，便于在宿主 CLI 的原生任务 UI 中呈现进度。

该项目是一个基于 MIT 协议开源的免费 AI 网关（AI Gateway），旨在为开发者提供统一的模型调用入口，让编程工作永不中断。项目通过单一 API 端点聚合了 290+ 家 AI 服务提供商（其中 90+ 家提供免费额度）和 500+ 种模型，覆盖 Kimi、Claude、GPT、OpenAI、Gemini、GLM、DeepSeek、MiniMax 等主流大模型。它天然兼容 Claude Code、Codex、Cursor、OpenCode、Cline、Copilot 等主流 AI 编程工具，开发者无需修改客户端即可无缝切换后端模型。核心功能亮点包括：配额感知的自动回退（Quota-aware auto-fallback），当某个提供商额度耗尽或不可用时自动切换到备用通道，保障调用连续性；基于 RTK 与 Caveman 的上下文压缩技术，可节省 15%-95% 的 token 消耗，显著降低使用成本；支持 MCP（Model Context Protocol）与 A2A（Agent-to-Agent）协议，方便与 AI Agent 生态集成；同时提供 Desktop 桌面端和 PWA 渐进式 Web 应用，覆盖多终端使用场景。项目由 500+ 位贡献者共同构建，社区活跃度高，是当前多模型统一接入方案中较为完整的开源实现之一。
在 AI 编程工具爆发的当下，模型碎片化与配额限制成为开发者痛点。该项目以 MIT 免费开源方式提供统一网关，兼具广度（500+ 模型）、经济性（token 压缩最高 95%）与生态兼容性（MCP/A2A、主流 IDE 工具），并拥有 500+ 贡献者的社区规模，是值得关注的多模型聚合基础设施方案。

mentor ⭐ 62

PythonuvMarkdown (SKILL.md)HTML/SVGClaude CodeOpenAI Codexskills.sh
mentor 是一款面向 AI 编程助手（Claude Code、Codex 等支持 SKILL.md 格式的智能体）的会话洞察技能。它在本地读取 ~/.claude 与 ~/.codex 下的会话历史与 rollout 记录，聚合多次会话的消息量、工具调用、编辑次数、涉及文件、token 消耗、每日活跃度、工具与语言使用比例等指标，随后由智能体基于真实提示与统计生成一份结构化分析，最终输出一份自包含的 report.html 报告。报告包含八个板块：工作主题聚类、智能体使用方式、亮点表现、摩擦点、值得尝试的功能、CLAUDE.md 补充建议、新用法与趋势展望，重点在于为每个摩擦点给出可复制的修复方案（如 CLAUDE.md 配置、hook 或习惯调整）。全流程本地运行，不上传任何数据，可通过 npx skills add 一键安装，也支持手动 git clone 到技能目录，并可作为每周复盘习惯运行。

通用版 Fable 5 系统提示词 ⭐ 406

跨模型通用的精简版 Claude 系统提示词

MarkdownPrompt EngineeringLLM System Prompt
该项目是对 Anthropic 公开的 Claude Fable 5 / Mythos 5 系统提示词进行的厂商中立化改造版本。原始提示词中包含大量专为 Claude 生产环境设计的基础设施内容，例如 XML 规范、工具接口、产品特定行为和内部实现指导，这些内容在迁移到其他前沿大模型时价值有限。项目通过过滤这些实现细节，保留可跨模型泛化的高价值行为指导原则，从而显著降低 token 消耗，提升上下文利用效率。仓库提供三个层次的版本以适配不同场景：core.md 为最小 token 的核心行为原则版本；balanced.md 为大多数场景推荐的平衡版本；complete.md 则保留了几乎所有厂商中立的行为指导。保留下来的内容涵盖用户意图理解、不确定性诚实处理、清晰自然的沟通、高质量代码生成、含权衡分析的实用建议、响应前的验证、客观纠错以及避免冗余元评论等关键能力。移除的内容包括 XML 包装、MCP 与工具基础设施、产品特定指令、UI 行为、存储与产物管理等。项目宣称已在 Claude、ChatGPT、Gemini、DeepSeek、Qwen、Grok、GLM 等主流模型上具备兼容性，使用者只需将对应 Markdown 文件粘贴到系统提示词字段即可。
该项目切入了一个具有争议性但价值明确的问题：当剥离厂商专属实现细节后，顶级模型的系统提示词中还有哪些行为原则真正值得沿用。它不是简单的提示词泄露搬运，而是通过结构化裁剪把 Claude 的行为工程经验转化为可移植资产，对希望构建自有 Agent 或对提示词工程感兴趣的开发者具有直接参考价值。
