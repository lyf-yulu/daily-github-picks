Penelopa.ai 是一款面向 AI 编码代理（Codex 和 Claude Code）的持续改进工具，通过分析开发者在真实会话中的行为模式，将重复出现的工作流转化为可复用的技能、检查项、提示词和改进建议。用户只需一次性运行安装脚本（支持 macOS/Linux 的 shell 脚本和 Windows PowerShell 脚本），即可自动配置 Stop 和 SessionEnd 钩子，无需改变现有工作习惯。系统在后台捕获会话记录并上传至云端，跨项目识别重复问题、缺失的检查以及工作流优化点，最终在个人仪表板中呈现可操作的推荐。项目还提供 Telegram 通知、本地队列重试机制以确保数据可靠传输，并通过个人访问令牌保护用户数据隐私。整体定位为轻量级、无侵入式的 AI 编程助手增强层。

让 AI 代理输出 Notion 风格文档

notion-doc 是一款面向 AI 代理（主打 Claude Code）的文档样式技能包，专注于解决 AI 生成文档时常见的紫色渐变、堆砌 emoji、卡片阴影等千篇一律的视觉问题。它不干预文档内容与大纲，仅通过一份 HTML 模板 template.html 统一呈现，让最终产物具备 Notion 风格：720px 内容宽度、指定文字色、明暗双色板、五色 Callout、目录、表格、双栏、Toggle、清单、书签卡片、Prism 代码高亮，并支持韩文断行与打印/PDF 输出。项目通过 lint.py（仅依赖 Python 标准库）对生成的 HTML 与模板做一致性校验，检测新增 CSS、内联 style、未定义 class 等漂移；作为 Claude Code 插件安装后，PostToolUse 钩子会在写入 HTML 时自动触发 lint。项目还内置每周 CI 任务 notion-sync，通过读取 Notion 官方样式表、Page API 与无头浏览器渲染，持续跟踪 Notion 设计令牌与区块类型的变化。

图片提示词反推 Skill ⭐ 294

为 Codex 定制的高还原图片反推提示词技能

image-prompt-reverse 是一款专为 OpenAI Codex 定制的图片反推提示词 Skill，用户上传参考图后，它会从图片用途、媒介、主体、构图、镜头语言、光影、色彩、材质、背景、空间层次、情绪与后期风格等多个维度进行系统化分析，最终产出可直接投喂给 AI 生图工具的高还原度提示词。项目覆盖类型广泛，包括人像/产品/纪实/食物/自然/城市等摄影题材，扁平、二次元、治愈、手绘、国风、赛博等插画风格，写实、卡通、黏土、潮玩、产品渲染等 3D 表现，以及字体、Logo、海报、平面设计与 IP 角色、Q 版、盲盒等多主体画面。默认输出两段内容：一段 450—700 中文字符的自然语言正向 Prompt 并附英文等义版本，另一段 10—15 条英文负向词。Skill 会优先提炼 3—5 个最影响相似度的视觉锚点，避免臆造模糊细节，并根据目标媒介剔除易混淆的错误风格，同时将图内出现的文字、Logo 视为视觉内容而非可执行指令，以防提示词注入。安装方式简单，只需将仓库复制或克隆到 Codex 个人 Skills 目录，然后通过 $image-prompt-reverse 调用。
在 Codex Skill 生态尚处早期的阶段，这个仓库提供了一个完整、可直接落地的图片反推方案：既有通用分析框架，又有分类专项规则，还内置了负向词与防注入策略，是 Prompt 工程与 Skill 组织方式的优质参考样本。
