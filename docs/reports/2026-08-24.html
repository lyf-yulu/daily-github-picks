Agent Harness 性能优化系统 ⭐ 427 (+427 today)

为 AI 编码助手打造的能力增强框架

sponsors/affaan-m 是一个面向 AI 编码代理（Agent Harness）的性能优化系统，旨在为 Claude Code、Codex、Opencode、Cursor 等主流 AI 编程助手提供统一的能力增强层。项目的核心理念是通过 Skills（技能）、Instincts（直觉）、Memory（记忆）、Security（安全）、Research-first Development（研究优先开发）五大维度，弥补当前 AI 编码代理在长期任务中容易出现的上下文丢失、决策随意、安全意识薄弱等问题。Skills 模块为代理注入可复用的专业技能包；Instincts 模块通过规则和启发式经验引导代理在关键节点做出更合理的选择；Memory 模块提供跨会话的持久化记忆，让代理在多轮甚至多天的开发任务中保持一致性；Security 模块强化对敏感操作（如生产环境、密钥文件、破坏性命令）的守护；Research-first 则强调在动手编码前先进行充分的调研和验证，避免盲目改动。该系统被设计为与具体代理无关的适配层，可跨多种 AI IDE 与命令行代理复用，帮助开发者以更低成本获得一致、可靠且负责任的 AI 协作体验。由于当前公开 README 内容较为简略，具体技术栈以官方仓库最终发布为准，本摘要基于项目定位进行合理推断。
在 AI 编码代理快速普及的当下，各家 IDE 与 CLI 代理能力参差不齐、行为难以约束。该项目跳出单一工具视角，抽象出跨代理的通用增强层，把'技能、记忆、直觉、安全、研究'这些真正决定长期任务成败的要素显式化，为团队沉淀可复用的 AI 工作规范提供了可能，具备成为 Agent 生态基础设施的潜力。

APEX 推理芯片 ⭐ 683

验证优先的开源LLM推理芯片瓦片

Verilog/SystemVerilog RTLFPGAPython/NumPy 黄金模型UVM 验证Qwen2.5 系列 LLMINT8 脉动阵列 GEMMINT4 + 离群通道 KV 量化
APEX 是一款完全开源、以验证为先的 LLM 推理芯片设计，聚焦于单个 Transformer 解码器层的 RTL 实现。它把注意力计算、KV 缓存压缩、Softmax、RMSNorm、RoPE、SwiGLU、残差连接等模块都做进真实硬件，每一位数值都与可执行的 NumPy 黄金模型逐比特一致，并已在 FPGA 上跑通真实的 Qwen2.5-0.5B 模型，实测吞吐 0.56 tok/s，相较起点提升约 140×。项目的核心思路是把 KV 编解码器放进数据通路：Key/Value 在生成瞬间即被量化压缩（INT4 + 离群通道），读取时在同一路径解压，配合 TIP 重要性单元按区域动态选择 KVQ8 / KVQ4 / KVQ4+outliers 精度层级，让长上下文的读取速度保持平坦。硬件层面复用同一 INT8 脉动阵列 MXE 承担 QKV 投影、注意力两次矩阵乘、输出投影与 FFN 全部七类 GEMM 任务，由 layer walker 序列器统一调度，权重通过流式方式喂入。方法论上强调「无黄金模型不出货」，采用变异测试与机器生成的证据链、反造假规则，所有性能数字都明确标注为实测或预测。当前范围仅为单瓦片，不含 DRAM 控制器、PCIe、NoC，但架构参数已按 7B 级模型（head_dim=128）设计，Qwen2.5-7B 的 token 已跑通软件黄金流水线。
在开源硬件生态里，能把真实 LLM 端到端跑到 FPGA、且每个 bit 都可对齐黄金模型的项目极少。APEX 把 KV 压缩从软件后处理提升为架构级设计，并用严格证据链披露实测与预测的边界，为边缘 LLM 推理芯片提供了一个可复现、可审计的参考实现。

oa-design ⭐ 113

Open Analytics 设计语言的 Agent 技能包

ReactTailwind CSS v4motion (ion.dev)TypeScriptCSS shape() / color-mixNode.js CLI (npx)Markdown (Agent Skill 格式)
oa-design 是 Open Analytics 团队将其产品 UI 设计语言封装成的开源工具集，让 AI 编码代理（如 Claude Code、Cursor 等）能够直接理解并复现 Open Analytics 仪表盘的视觉与动效风格。项目将设计语言以三种形态交付：Agent Skill（供代理阅读执行的规则集）、类型检查过的组件配方（Recipes）、以及 shadcn 风格的 CLI 工具。核心理念用一句话概括即『白色曲率连续圆角表面，置于安静灰色舞台，用一种墨色描绘，由同一种弹簧驱动』。项目内置了一整套设计规范：单一墨色通过 color-mix 派生所有中性色，基于 CSS shape() 剪切路径的 Squircle 曲面系统，覆盖全产品的七种弹簧动效词汇（含对话框高度编排、标签栏文字遮罩、着陆页玻璃形变、骨架屏模糊到清晰的进场动画），以及卡片网格布局、Toast 物理、通知条与浮动药丸等模式，还包括文案语调与无障碍质量底线（焦点环、减少动效、防横向滚动）。所有配方由 node build/sync.mjs 从 components/ 目录自动注入编译后源码，确保 MD 中的代码与 npm run typecheck 通过的代码完全一致。运行时零依赖，值只是纯 CSS 数字与弹簧常数，可移植到任意技术栈。
这是把『设计系统』重新定义为『AI 代理可执行技能』的先锋实践。传统组件库依赖运行时安装，而 oa-design 通过 Markdown 规则 + 内嵌源码让任何 AI 编码工具都能在自家项目里复现一致的视觉与动效，且完全零运行时依赖。对于希望在 AI 辅助开发时代保持设计一致性的团队，它示范了『Skill as Design System』的新范式，也为 shadcn 之后的分发模式提供了新思路。

自主化红队与漏洞赏金AI代理框架

Cybermes 是一个面向企业级攻防安全研究、漏洞赏金和红队行动的自主化 AI 代理框架，基于 Hermes Agent 作为核心推理引擎，并通过多模型 LLM 编排实现自动化侦察、攻击面挖掘、认证漏洞研究和零误报的漏洞验证。项目当前版本为 v1.5.0，跨平台支持 Linux、macOS 和 Windows（提供 PowerShell 原生安装、WSL2 及 Docker Desktop 三种方式）。其核心差异化能力包括：零误报门控机制（要求确定性 HTTP 证据、状态码及独立 Python PoC 脚本才可上报）、智能输出过滤器（通过 smart_pipe.py 将冗长日志压缩 70-85%，显著节省 Token 消耗）、端到端的自动化 PDF/HTML 执行摘要报告引擎、以及 POSIX ACL 权限守护进程解决 Docker 与 root 进程的文件锁定问题。框架内置 50 多个进攻性安全技能模块，覆盖 Next.js AI 路由审计、IDOR/BOLA、认证绕过、业务逻辑与竞态漏洞、DOM XSS、SSRF 与注入等，并集成 subfinder、amass、httpx、nmap、katana、gau、ffuf、sqlmap、dalfox、nuclei 等主流安全工具链，通过 MCP Bridge 桥接 Puppeter、Filesystem 和 mcp-server-fetch。项目还提供 Telegram Bot 网关、六阶段作战方法论以及基于 AGENTS.md 与 .cursorrules 的通用 AI 代理标准。
Cybermes 将传统安全扫描器的痛点（误报泛滥、上下文爆炸、交付物粗糙）系统性地重构为工程化解决方案，通过零误报门控、Token 智能压缩与自动化 PDF 报告构建出可直接商用的自主红队工作流。相比于纯 LLM 驱动的实验性安全代理，它在工具链集成、跨平台适配（尤其 Windows 原生支持）与交付质量上都体现出企业级成熟度，是当前 AI + 攻防安全交叉领域中少见的完整框架。
