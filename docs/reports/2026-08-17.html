HERO 反过度防御契约 ⭐ 166

一段配置制止 AI 编码代理过度防御

MarkdownPrompt EngineeringAGENTS.md / CLAUDE.md 约定
HERO（Anti-OverDefense）是一份可直接粘贴到 AI 编码代理配置文件中的约束契约，用于抑制代理在写代码时表现出的四类过度防御行为：Hashing（无谓的哈希与校验和）、Edge cases（对不可达边界情况的执念）、Rubrics（机械化评分与自我审计循环）、Overbuild（多余的兼容层、迁移框架和特性开关）。项目作者观察到这些代理常常优化「不被指责」而非「把事做好」，于是把四种模式命名为 HERO，方便在协作时直接指认「刚才发生了哪一种」，而不是陷入感觉之争。仓库核心是一段中英双语的 SCOPE LIMITS 规则块，配套六条明确边界，包含一条重要例外：不覆盖用户实际请求的安全、迁移或审查工作。用户只需把它粘贴进 CLAUDE.md、AGENTS.md、.github/copilot-instructions.md、.cursorrules 等代理会自动加载的文件即可生效，兼容 Claude Code、Codex、Antigravity、Cursor、Copilot、Windsurf、Gemini CLI 等主流工具，无需安装。仓库还提供 cases 案例目录（在代理狡辩时作为反驳素材）、hosts 目录（说明各代理的粘贴位置）和 examples 目录（社区贡献者在自己项目中的适配范例）。项目源自作者另一个 13.7k★ 的 ARIS 项目的观察沉淀，专注于把跨模型审阅的价值留下、把「哈希税」丢掉。
它抓住了当下 AI 编码代理最普遍却最难描述的痛点——用堡垒式代码淹没真正的功能实现，并用一份四十行的可粘贴契约给出了跨工具的通用解法。命名化的 HERO 框架为团队与代理之间提供了共享词汇，衍生自 13.7k★ 的 ARIS 项目背景也让其经验密度显著高于普通提示词模板。

Vibe Coding Toolkit ⭐ 149

生产级 AI 编码工作流工具箱

Claude CodeOpenAI CodexSuperpowers 插件ESLintBiomeContext7ObsidianNode.js / npmMermaidMarkdown 模板
Vibe Coding Toolkit 是一套面向 Claude Code（同时兼顾 OpenAI Codex）的 AI 辅助编码工作流工具箱，由巴西开发者 Matheus Gomes 从真实金融科技生产项目（受 NDA 保护）中提炼并脱敏而来。作者认为「粘贴一个大 prompt 然后祈祷」不是工作流而是靠运气，因此把每天在生产环境实际使用、能解决具体问题的做法整理成可复制的模式：会话失去主线、agent 越权多写、lint 警告长期无人清理、每次新会话都要重复踩坑等痛点，都对应了工具箱里的一块拼图。核心是 Superpowers 插件——被作者视为整个工具箱最强的一环，负责逼迫 agent 先探索意图、做计划，再落笔写代码，而不是一上来就实现最先想到的方案。围绕它构建了一整套配套：并行波次的 subagent 编排协议（以结构而非纪律来消除文件冲突和 commit 争抢）、ESLint/Biome quality gates（把警告升级为错误，用 lint 强制架构边界）、Graphify + Context7 的代码地图、RTK token 代理、Ponytail / Caveman 人格约束、以及 Claude 原生记忆加 Obsidian 的跨会话上下文。仓库同时提供 CLAUDE.md 模板、`/aia-harness:init` 一键初始化命令，以及从安装到首个被评审 commit 的完整 Playbook。
与市面上大量「Prompt 合集」不同，这个仓库把 AI 编码从个人技巧提升为可复用的工程流程：subagent 波次编排、lint 质量门、跨会话记忆等做法直接来自受 NDA 保护的金融科技生产项目，且每条实践都对应一个真实踩过的坑。对已经在用 Claude Code / Codex、想把「碰运气式 vibe coding」升级为团队级工作流的开发者，参考价值远超普通模板集。

Lore ⭐ 158

编码 Agent 会话的本地可搜索归档

RustTauri 2SQLiteReactTypeScriptNode.jsGit
Lore 是一款面向编码 Agent 用户的本地桌面应用，专门用于浏览和搜索 Claude Code 与 Codex 的会话历史。它的定位是「编码 Agent 的 Git 记忆」，通过只读方式解析这两款工具在本地保存的会话文件，将其与对应仓库及 Git 提交历史关联起来，统一汇入一个可搜索的本地档案库。与 Agent 包装器或代理服务不同，Lore 不介入 Agent 运行流程，也不修改其原始文件，只做被动归档与检索。项目在架构上采用分层设计：底层由只读适配器读取 Claude Code 和 Codex 的日志，中间层通过 lore-core 完成数据摄取、存储、Git 关联、搜索与安全处理，将结果写入本地 SQLite 归档并保留 Git 证据；上层通过 Tauri 2 桥接 Rust 后端与 React 前端，为用户提供桌面级浏览与搜索界面。值得注意的是，Lore 明确区分不同类型的「证据」——例如会话期间记录的提交与后续摄取时观察到的仓库状态被视作独立事实，避免混淆。V0 版本坚持完全本地化，不设账户、遥测、云数据库或 LLM 调用，隐私优先。当前版本聚焦 Claude Code 和 Codex 两大生态，刻意推迟更多集成与生成式技能，先把核心归档能力打磨扎实。
在编码 Agent 快速普及的当下，会话记录散落在各家工具的本地目录里，缺乏统一检索手段。Lore 用「Git 记忆」的视角切入，把 Claude Code 与 Codex 的历史变成可搜索的本地知识资产，且坚守只读、本地化、无遥测的工程克制，对关注隐私与可追溯性的开发者极具吸引力。

面向 Codex 的中文插画风格技能合集

沐阳插画 Skills 是一套专为 Codex 打造的中文插画生成技能合集，聚焦于「固定风格配方」这一核心思路。项目包含 1 个总入口技能与 8 个风格子技能，覆盖 25 套预调好的插画配方，涵盖极简编辑、撞色时装、柔焦梦幻、纯白高定、暗黑时尚、东方诗意、复古印刷与电影叙事八大类别。使用者只需明确「主体」与「具体风格」两项信息，Skill 会在内部套用预设提示词直接生成图片，全程不展示中间提示词，也不会擅自扩写主体或混合风格，从而保证输出风格的稳定与可复现。项目提供总入口路由与子技能直呼两种调用方式，并支持自定义画幅参数。安装方式为将 skills/ 目录下的 9 个子目录复制到本地 ~/.codex/skills/ 目录，兼容 macOS、Linux 与 Windows PowerShell。每种风格均配有独立的 references/recipes.md 配方文件与 assets/ 示意图，便于用户提前预览效果。整体交互采用中文，并在缺失主体或风格时主动追问，避免生成偏差。项目定位清晰，属于 Codex Skills 生态下的一款风格化图像生成工具包，将设计师的经验沉淀为可复用的提示词资产。
这是 Codex Skills 生态中少见的中文风格化图像技能合集，把设计经验固化为 25 套可复用配方，用「主体 + 风格」两输入即可稳定出图，为国内创作者提供了一套开箱即用的插画工作流范例，也示范了如何用 Skills 组织提示词资产。
