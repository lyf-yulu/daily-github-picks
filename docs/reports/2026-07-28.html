applied-micro-skills 是一套面向 Claude Code 和 Codex 的技能集合，专为应用微观经济学实证研究流水线设计。仓库包含 18 个相互独立的技能文件夹，覆盖从文献检索、数据获取、LLM 辅助分类标注、计量估计，到表格图形制作与文档交付的完整链路。核心亮点是可复现性审计（adversarial-empirical-review），它会在隔离副本中从原始输入重跑整个流水线，要求再生表格与稿件完全一致。LLM 方法簇提供了标注输入平权检查、金标准可行性诊断、模型漂移守门、AsyncOpenAI 并发优化和裁决工作表等一整套避免自欺的验证工具。计量层集成 WRDS 数据接入、pystata 驱动、pyfixest GPU 加速与事件研究 CAR 引擎（对齐 Stata eventstudy2）。输出层则包含 estout 风格 LaTeX 表格、Stata stcolor 配色的 matplotlib 图形、引用置放、LaTeX 转 Word 与 Markdown 转 PDF 等交付工具。每个技能自成一体，可整体安装或按需拷贝。

Karpathy 风格 Claude Code 行为准则 ⭐ 305

把 Karpathy 的 LLM 编码痛点转成规则

Claude CodeCLAUDE.md 约定Cursor Project Rules (.mdc)Markdown
本项目是一份面向 Claude Code（以及 Cursor）的行为准则集合，灵感来自 Andrej Karpathy 关于大语言模型在编写软件时常犯错误的现场笔记。作者将 Karpathy 观察到的典型问题——例如模型会替用户做出错误假设并一路执行、不主动澄清疑惑、不呈现权衡、倾向过度设计与过度抽象、以及在与任务无关的地方擅自修改注释和代码——提炼为四条可直接落地的原则：一是「先思考再编码」，要求显式声明假设、呈现多种解读、必要时反推需求；二是「简洁优先」，只写解决问题所需的最小代码，避免臆想式扩展；三是「外科手术式修改」，只动必须动的地方，不顺手重构相邻代码，仅清理自身改动引入的孤儿代码；四是「目标驱动执行」，把命令式任务转化为可验证的成功标准（如先写复现测试再修复），并对多步任务给出带校验点的简短计划。项目提供两种落地方式：通过 fastsetup 安装为 Claude Code 插件（`/plugin install andrej-karpathy-skills@karpathy-skills`）在所有项目中生效，或将四条原则写入项目根目录的 `CLAUDE.md`。同时仓库内置 `.cursor/rules/karpathy-guidelines.mdc`，让 Cursor 用户也能复用同一套规则。整体基调偏向「谨慎优先于速度」，鼓励在非平凡任务上多做澄清与验证，对琐碎改动则允许自行裁量。
在「AI 编程助手如何被正确使用」话题热度极高的当下，这个仓库不谈模型能力，而是从工程实践角度回答「怎么约束模型行为」。它把 Karpathy 这样一线研究者的经验，转成任何团队都能复制粘贴的准则文件，几乎零成本落地，且同时覆盖 Claude Code 与 Cursor 两大主流环境，是 Prompt/规则工程领域一个小而精、可立即受益的范例。

BOSS 控制台 ⭐ 199

AI 智能体的开源多平台操作台

Kotlin MultiplatformCompose MultiplatformJVMMCP (Model Context Protocol)Supabase Edge Functions嵌入式浏览器 Fluck
BossConsole（BOSS）是由 risa-labs-inc 开源的首个多平台 AI 智能体操作台（harness），采用 Apache-2.0 协议发布，面向企业、科研与研究场景。它将嵌入式浏览器（Fluck）、可共享终端（BossTerm）、代码编辑器、可扩展插件工具箱（Toolbox）以及受治理的 MCP 工具层整合为一个桌面工作空间，用于复杂的 AI 辅助任务。与 Claude Desktop、Codex、Google Antigravity、Cursor、Windsurf/Devin 等闭源竞品不同，BOSS 支持 BYO Agent，可自由接入 Claude Code、Codex、Gemini 或 OpenCode 等主流智能体。其独特之处在于双向定位：既是智能体的运行家园，也是可被智能体操作的应用——同一套 MCP 层将 BOSS 自身的标签页、终端、浏览器、编辑器、Git、密钥与自动化功能以 100+ 个 mcp__boss__* 工具的形式暴露给智能体，既提供只读的情境感知能力，也提供可执行的动作工具，让 AI 能自主完成多步骤任务。BOSS 基于 Kotlin Multiplatform 与 Compose Multiplatform 构建，运行于 JVM 而非 Electron，支持真正的多线程与插件运行时热重载，并结合 Tool Evolver 让智能体可自行演化工具。它内置企业级细粒度 RBAC 与紧急停止（kill-switch），可通过密钥管理器安全填充登录凭证而不暴露给模型。终端会话可通过二维码分享至手机等任意设备，支持端到端加密与多用户协作，覆盖 macOS、Windows、Linux（x64 与 ARM64）全平台。
BOSS 填补了 AI 智能体桌面工具赛道中开源与多厂商中立方案的空白。它不仅让智能体拥有真实的浏览器、终端与编辑器，还首创将应用自身作为可操作对象暴露给智能体的双向架构，配合运行时热重载与工具自演化，为科研、企业级复杂工作流提供了从笔记本到超算的可扩展底座；跨平台原生实现与细粒度治理机制也让它在安全性与性能上明显区别于 Electron 类竞品。

Open Image Prompts ⭐ 106

本地优先的开源视觉提示词档案库

Python 3 + uvNode.js 20/22SQLite（只读 immutable + FTS）前端（Vite，默认端口 5173/4173）DockerAgent Skills (npx skills)
Open Image Prompts 是一个开源、本地优先的视觉提示词（Prompt）档案项目，致力于提供可溯源的「提示词-图像」参考语料库，并配套两个可安装的 Agent Skills：`img-gen-taste` 将粗略需求转化为清晰的艺术方向，`img-gen-prompts` 基于本地数据检索可溯源的提示词与图像参考并打开本地对比画廊。公开数据集规模可观，包含 13,907 条源提示词、24,049 张图像、27,814 条双语翻译、161,720 条 v2 版本活跃标签，以及封闭式的 185 个视觉标签分类体系。项目在工程实践上做了精细拆分：Git 仓库仅追踪代码、前端、API、Skills、分类法与轻量元数据，而体量较大的 SQLite 数据库（约 80MB）与按月切分的图像包（合计约 4.3GB）通过 GitHub Releases 分发，并使用 sha256 校验，避免了 Git LFS 带来的膨胀问题。用户通过 `start.sh` 或 `start.bat` 一键启动，脚本会自动安装 uv、构建 Python 环境、拉取数据集、安装前端依赖并启动服务；亦支持 Docker 镜像构建与运行，内置健康检查和非特权用户。所有服务默认绑定 127.0.0.1，SQLite 以只读 immutable 模式打开，永不触发标注任务，安全边界清晰。
该项目在开源生成式 AI 提示词生态中提供了一种务实的「本地优先 + 可溯源」范式：不依赖云端向量库或付费 API，纯靠 SQLite FTS 与结构化标签体系即可完成高质量的提示词检索，同时以 Agent Skills 形式对接编码代理，让开发者可以直接在本地工作流中调用。数据集规模与工程规范并重，Releases 分发、sha256 校验、只读 SQLite、回归测试基准（72 条双语查询）等细节体现出成熟的产品化思路，对希望构建可复现提示词库或研究图像风格分类法的开发者具有较强参考价值。

本仓库是作者 realchendahuang 分享的一份可直接复刻的 Pi（@earendil-works/pi-coding-agent）终端 AI 编码代理配置，以教程形式组织。项目整合了 17 个精选插件、18 个全局 Skill 和 2 个 MCP server（context7、chrome-devtools），并附带一键安装脚本 install.sh，可自动执行 pi install 并合并 MCP 配置到 ~/.config/mcp/mcp.json。README 系统讲解了 Pi 的分层架构（TUI、Agent Loop、Providers、Tools、Extensions、Skills、Themes、Packages）以及三档改造方式：轻量写 Skill、中量接入 MCP Server、重量编写 TypeScript Extension。插件覆盖代理编排（pi-subagents 支持 single/chain/parallel/async/forked-context 五种模式）、目标驱动（pi-goal）、只读计划模式（pi-plan-mode）、AST 级代码理解（pi-lens 基于 ast-grep 与 tree-sitter）等场景，目标是把 Pi 打造成能多代理协作、省 token、能跑浏览器的全能终端编码代理。
