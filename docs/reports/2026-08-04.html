codex-vision-proxy ⭐ 253

让纯文本模型在 Codex 中看图

Python 3.11+OpenAI 兼容 Chat Completions APIvtracerPillowCodex Skills
codex-vision-proxy 是一个为 Codex 环境设计的视觉代理方案，专门解决纯文本模型（如 DeepSeek V4）无法调用内置 view_image 工具的痛点。项目通过在 Codex 与上游模型之间架设一层 OpenAI 兼容的代理服务，拦截包含图像的请求，将图像转交给多模态视觉模型处理，再把结果以文本形式回填给纯文本主模型，使其在体验上尽可能贴近多模态模型，且无需额外的 MCP、Skill 或 CLI 配置。区别于常见的通用图像描述封装，本项目最大的特色是保留了「智能体为何要看图」的意图：它会从用户消息或助手调用 view_image 时给出的 reason 中抽取 focus hint，作为聚焦提示传给视觉模型，从而生成任务相关的针对性描述，而非泛泛的通用 caption。项目同时支持粘贴图像（message.content）与 view_image 返回（function_call_output.output）两种输入路径，并对同一请求中的多张图片进行并发处理，将 N 张图的耗时压缩到接近单张。除代理本体外，还附带了一套面向纯文本 LLM 的视觉工具包：glance（图像问答/OCR）、ground（自然语言定位并返回像素级 bbox）、detect（区域元素清单化）、trace（基于 vtracer 的本地确定性图像转 SVG），并提供可通过官方 skills CLI 安装的 vision-tools Skill，覆盖从 UI 调试、截图分析到 GUI 自动化与 Computer Use 等典型场景。
在多模态模型成本较高、许多开发者仍使用 DeepSeek 等强文本模型跑 Codex 的当下，本项目用一层轻量代理巧妙地把「看图」能力桥接给纯文本模型，且通过 focus hint 保留任务意图这一细节，明显优于传统的通用描述封装；配套的 ground/detect 更让纯文本 Agent 具备 GUI 操作与 Computer Use 潜力，实用性和思路都值得关注。

CEE 认知执行引擎 ⭐ 54

确定性优先的 Agent 工作流执行引擎

Go 1.26+Go 标准库（net/http）JSON 清单 DSLOpenAI 兼容 LLM 接口Mermaid 文档GitHub Actions CI可选卫星模块：Docker/HTTP Sandbox、WASM Hooks
CEE（Cognitive Execution Engine）是一个用 Go 编写的、以确定性为先的 Agent 工作流执行协议。项目的核心理念是：由确定性状态机驱动执行流程，LLM 仅在边缘负责将非结构化输入转换为结构化字段，不参与任何流程决策。核心模块零外部依赖，仅使用 Go 标准库，可离线构建与测试。它通过 JSON 清单（L1 无代码插件）或搭配 Go Hooks（L2 插件）来接入业务领域，无需修改引擎代码。运行时由 intentrouter（意图路由）、execution（DAG 执行、熔断、挂起恢复、补偿、并行）、llminjector（模式裁剪的边缘抽取）、sandbox（预执行只读探针）等组件构成。项目还内置了 replay 回放、scorecard 打分、bench 排行榜、CLI 工具与 HTTP 端点，覆盖退款、代码审计、安全监控、人工审批、加密市场异常检测等九个可运行示例。

南鸢写真提示词 ⭐ 194

人像写真中文提示词 Agent Skill

Agent Skill (SKILL.md 规范)npx skills CLIMarkdown 提示词工程MIT License
南鸢写真提示词是一个面向人像与写真摄影场景的 Agent Skill，通过 npx skills 工具链一键安装到本地 Agent（如 Claude Code 等支持 Skill 生态的客户端），为用户提供结构化的中文写真提示词生成能力。项目定位清晰：只负责产出高质量提示词，不直接调用图像模型生图，最终成片需将提示词交由外部图像模型渲染，从而保持与具体绘图工具解耦，具备较强的可移植性。功能层面覆盖多种典型使用场景，包括依据主题从零撰写完整中文提示词、构建系列母版并派生同系列变体（保持整体风格但避免构图、动作、服装重复）、生成适配网页端抽卡玩法的关键词组合，以及对参考图进行拆解还原。在专业性上，Skill 对成像逻辑做了细分处理，明确区分固定成像机制、单张现场光线以及皮肤区域反射，规避了直闪近景常见的全脸油膜等瑕疵，体现出对摄影布光与人像后期审美的深入理解。项目通过 SKILL.md 承载完整规则，README 主要说明安装、使用与更新流程，并提示当前任务不会热更新已加载 Skill，需重启会话生效。整体基于 Skills 规范打包分发，采用 MIT 开源协议。
在通用 AI 绘图提示词泛滥的背景下，该项目把摄影领域的专业知识（布光、反射、系列一致性）沉淀为可复用的 Agent Skill，而非停留在散装 Prompt。它示范了 Skill 作为垂直领域知识载体的形态：与图像模型解耦、可版本化更新、可被任意兼容 Agent 加载，对希望把摄影或美学专家经验产品化的创作者具有较高的参考价值。

Hermes Control ⭐ 50

移动端优先的 AI 运行时控制台

Node.js 20+JavaScript (ESM)Server-Sent Events (SSE)PWAHTTP/Cookie AuthCodex CLI (JSONL 子进程)Hermes WebUI
Hermes Control 是一个面向浏览器与手机的事件驱动控制台 PWA，用于监控和操作 Hermes WebUI 与本地 Codex CLI 两类 AI 运行时。项目采用 CLI 优先的开源思路，通过独立的适配器边界统一了提示提交、流式输出、会话与任务管理、运行时状态、审批、推理展示以及 STOP 控制等能力，让 PWA 前端消费一套规范化的事件契约，而无需感知底层来自 Hermes 还是 Codex。Hermes WebUI 作为外部 HTTP 依赖接入，Codex CLI 则以本地子进程方式启动并读取 JSONL 输出，服务端通过统一的 EventBus 广播归一化领域事件，并借助 SSE 将实时更新推送到手机。该版本明确排除 Codex Desktop、CDP、渲染器自动化及任何私有协议，目前为 v0.1.0-alpha，已通过 13 项自动化测试及本地 API 冒烟检查，适合单用户本地场景与社区二次开发。
