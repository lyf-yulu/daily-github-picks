swissdevjobs-cli 命令行工具 ⭐ 88

终端搜索薪资透明的技术岗位

Python 3.9+Python 标准库（stdlib-only）SQLiteMCP (Model Context Protocol)Claude Code Pluginuv / uvx / pipx
swissdevjobs-cli 是一款零依赖的 Python 命令行工具，聚合了 8 个国家、9 个招聘平台的技术岗位数据，涵盖瑞士、德国、英国、美加、荷兰、法国、新加坡等地约 4700 个薪资透明的技术职位，并额外接入 jobs.ch、jobup.ch 的约 5 万条瑞士全行业岗位以及新加坡 MyCareersFuture 约 9000 条 IT 岗位。核心特色是将薪资作为一等过滤条件，支持 --min-salary、--remote、--tech 等多维筛选，并通过解析 MongoDB ObjectId 还原真实发布时间，避免被平台的重新置顶误导。工具使用本地 SQLite 记录已投递岗位实现自动去重，仅使用 Python 标准库无第三方依赖。除 CLI 外还内置 MCP 服务器与 Claude Code 插件，所有命令支持 --json 输出，方便 LLM Agent 调用；同时可智能识别无法直投的岗位并给出替代申请入口。
在 AI Agent 时代，将传统的求职门户改造为 Agent-native、JSON-first 的命令行 + MCP 工具，展示了零依赖 Python CLI 与 LLM 集成的优秀实践。

GitNexus 是一款完全运行在浏览器端的代码智能分析引擎，定位为「零服务器（Zero-Server）的客户端知识图谱构建工具」。用户只需将 GitHub、GitLab、Azure DevOps 上的 Git 仓库地址粘贴进来，或直接拖入本地 ZIP 压缩包，GitNexus 便会在本地浏览器中完成源码解析，并生成一张可交互的代码知识图谱，帮助开发者快速理解陌生项目的结构、依赖与调用关系。与传统需要后端服务的代码分析平台不同，GitNexus 将解析、图谱构建、向量检索与 LLM 推理全部下沉到浏览器，从根本上避免了源代码上传到第三方服务器带来的隐私与合规风险，特别适合企业内部代码库或敏感项目的探索场景。项目还内置了一个 Graph RAG Agent，可以基于生成的知识图谱进行自然语言问答，让开发者以对话方式追踪函数调用链、定位关键模块、分析代码演进。整体来说，GitNexus 将「代码可视化 + 图谱检索 + 大模型问答」三种能力融合到一个纯前端应用中，是代码理解、Onboarding、架构梳理与技术债盘点的高效工具。
GitNexus 用「零服务器」的架构挑战了传统代码智能平台的部署模式，把 Parser、知识图谱、向量库与 RAG 全部塞进浏览器，既解决了源码隐私痛点，又降低了使用门槛；同时它把 Graph RAG 落到了「代码」这个高度结构化的语料上，是当前 AI Coding 赛道中少见的、把图谱与检索增强真正结合的探索型项目，对代码理解工具与本地化 AI 应用方向具有参考价值。

sepia 是一个基于 Agent Skill 规范的可移植写作技能包，同时支持 Claude Code、Codex、Grok Build 与 Antigravity 四大 AI 编程环境，用一份规范化的 SKILL.md 实现跨平台一致行为。项目定位于「去 AI 味」写作，但切入点不同于常见的润色型 humanizer：它以 StoryScope（arXiv:2604.03136）等 12 项研究为证据基础，指出仅凭叙事结构特征就能以 93.2% macro-F1 检测出 AI 小说，而表面文风改写几乎无效。因此 sepia 针对虚构文本提供三层修复流程——第一层修复叙事架构（弱化因果链、后置揭示、混合情绪表达、稀疏人物网络等），第二层调整段落级话语流，第三层再处理陈词滥调与句式模板；并附带 30 项诊断量表和针对 Claude、GPT、Gemini、DeepSeek、Kimi 的模型指纹校正。对专业文本（发布说明、PR 回复、事故复盘、工单、技术文章）则提供按场景匹配的规则集与共享的 slop 清单。技能提供 write、review、refactor、recreate 四种操作，并遵循「向人类分布校准而非反转 AI 分布」的原则，每次仅选用 3–5 条修改以避免形成新指纹。安装方式覆盖各平台原生 marketplace、统一 install.sh 脚本以及 npx skills，支持用户级与项目级两种作用域。
多数 AI 去味工具停留在换词改句，sepia 是少数把学术证据（StoryScope 等 12 篇论文）工程化为可执行 Agent Skill 的项目：它把「AI 味」的真实来源——叙事结构、情感表达模式、真实世界指涉的缺失——转化为可诊断、可修改的规则，同时坚持「不反转 AI 分布，只向人类分布校准」，避免生成新指纹。加上跨四大 Coding Agent 的统一分发方案，对关注 AIGC 检测对抗、写作辅助与 Agent Skill 生态的开发者都有参考价值。

CDAF 视频描述缓存格式 ⭐ 97

视频侧车格式，让AI别重复看片

Python 3.10+Node.js (npx skill 安装器)Gemini Files APIffprobe (可选)MarkdownSHA-256npm (cdaf-skill 包)
CDAF（Cached Descriptive Asset Files）是一个开源的视频侧车文件格式规范，旨在解决 AI 智能体重复分析同一视频造成的高昂 token 成本问题。它在视频文件旁生成同名的 .cdaf 纯文本文件，包含 SHA-256 哈希、字节大小、时长等头部元数据，以及摘要、分段时间戳、转录文本、屏幕文字和标签等 Markdown 正文。AI 智能体在处理视频前先校验哈希新鲜度，若匹配则直接读取几百 token 的文本描述，替代完整的多模态视频理解。项目提供完整生态：规范文档 SPEC v1.0、零依赖的 Python 核心解析库、cdaf 命令行工具（generate/validate/read/status）、基于 Gemini Files API 的生成器、可通过 npx cdaf-skill 一键安装的 Claude Code 智能体技能包，以及可复现的基准测试。实测显示，在 gemini-2.5-flash 上准确率相当（20/20 对 19/20），prompt token 消耗降低 10.1 倍，延迟降低约 35%，规模化生产中视频工作流 AI 成本降至 1/25。
在 AI 智能体大规模处理视频的场景下，提出了一种极简且可验证的缓存范式：用纯文本 + 哈希新鲜度校验替代昂贵的多模态重复推理，既有规范、参考实现、CLI、智能体技能，又有可复现基准和 arXiv 预印本，形成完整的开源标准雏形，对 agentic 视频编辑工具（Remotion、HyperFrames 等）具有直接落地价值。

同花顺 Agent ⭐ 147

让 AI 助手直连本机同花顺行情与交易

C# (同花顺本机插件)Python (MCP 服务与配置器)MCP (Model Context Protocol)REST API (127.0.0.1:17180)Windows 10/11AGPL-3.0-only
同花顺 Agent 是一个面向同花顺远航版桌面客户端的非官方本机 AI Agent 连接工具，由独立开发者维护，与同花顺官方无授权或合作关系。项目目标是让用户能够在 Codex、Claude Code、WorkBuddy、ZCode、OpenClaw、DeepSeek Harness 等主流 AI 助手中，通过自然语言直接查询本机同花顺客户端里的实时行情、盘口、K 线、账户资产、持仓、LV2 逐笔委托和成交数据，甚至可选择性开启下单、撤单和改单等交易能力。功能实现依赖用户当前登录的同花顺账户与相应服务权限，插件本身不新增任何行情或交易权限。所有功能全部免费开放，不设订阅、会员或付费解锁。架构上，项目在本机 127.0.0.1:17180 暴露带随机访问令牌的 REST/MCP 接口，供 AI 助手调用；核心 C# 插件负责与同花顺客户端交互，Python 侧提供 MCP 服务、配置器和传输桥。数据全部在本地处理，不上传至维护者服务器，交易工具默认关闭并需二次人工确认，兼顾了易用性与安全边界。项目遵循 AGPL-3.0-only 协议，C# 本机插件暂闭源，并提供 SHA-256 清单供用户校验。
国内 A 股散户与量化爱好者一直缺少把本地行情客户端接入大模型的顺畅通道，该项目填补了同花顺客户端与 AI Agent 之间的空白：通过 MCP 协议直连本机同花顺远航版，覆盖行情、K 线、账户、LV2 逐笔等关键数据，还支持可选交易能力；同时坚持数据本地化、随机令牌鉴权、交易需确认等安全设计，兼顾实用性与合规边界，对研究 AI Agent 在金融场景落地的开发者有较高参考价值。
