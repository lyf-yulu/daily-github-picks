Bang Motion ⭐ 117

浏览器动效图形的AI Agent技能包

Agent Skills 规范Claude Code PluginHTML/CSS/JavaScriptGSAPWebGLNode.jsPuppeteerffmpeg
Bang Motion 是一个面向 AI 编程代理（Claude Code、Codex、Gemini CLI、Cursor 等）的 Agent Skill，用于在浏览器中生成真正意义上的动效图形，而非常见的“幻灯片式”视频。项目遵循开放的 Agent Skills 规范，通过 SKILL.md、references、assets、scripts 等目录组织指令、模板和脚本，并同时以 Claude Code 插件形式发布，可通过 /plugin 命令安装与更新。产出物是单个 index.html，双击即可自动播放、循环，无播放器 UI，观看侧仅需浏览器和 CDN 加载的 GSAP 与字体，不需要 npm install。项目覆盖开场片头、产品促销、bumper、频道 ID、动态字幕、下三分之一字幕以及五种解说风格（卡通拼贴、视觉新闻、白底目录、复古素描、连续动作矢量），并强制要求先写“风格简报”再写代码：调色板取自品牌、字体、背景表面、背景运动、转场、动态签名等都必须从菜单中选择，且不得与历史项目重复，从结构上防止代理套用廉价默认样式。技术上采用确定性时间轴，每一帧都是时间的纯函数，因此可精确刷动与逐帧导出；配合 ?debug=1 刷动条与 ?clean=1 导出模式；语音同步流程支持 ffmpeg 或纯浏览器停顿检测脚本；可选用 Puppeteer + ffmpeg 完成截帧与 MP4 导出。代理在交付前会自检反幻灯片规则：场景切换必须来自世界或相机运动、至多两级文字、每秒都有动作、至少两种转场且含真实景深过渡。
多数 AI 生成的“视频”本质是滑动的幻灯片，Bang Motion 用一份 SKILL.md 把动效设计的行业直觉（持续世界、相机运动、菜单化选型、反重复约束）转成代理可自检的结构规则，配合确定性时间轴和单文件 HTML 交付，展示了 Agent Skills 作为“可执行设计规范”的一种成熟形态，对希望把领域经验固化到 AI 工作流的团队有直接借鉴价值。

Penelopa.ai ⭐ 113

AI编程代理的持续改进平台

Node.js 24.xElectronTypeScriptPlaywrightShell / PowerShell 引导脚本Codex Hooks / Claude Code Hooks
Penelopa.ai 是一款面向 AI 编程代理（Codex 与 Claude Code）的持续改进工具，定位于通过分析真实编码会话来提炼可复用的工作流资产。项目通过在本地为 Codex 和 Claude Code 安装 Hook（Stop 和 SessionEnd 事件钩子）来捕获会话数据，将事件上传到服务端进行模式分析，识别用户反复出现的工作流模式，并转化为可复用的 skills、checks、prompts 和推荐建议，最终在个人 Web 仪表盘或桌面伴侣应用中呈现。安装脚本会下载经过校验的私有 Node/npm 运行时，无需依赖系统 Git、Python、Homebrew、Xcode 等前置环境，也不修改全局 PATH，安装过程较为独立与安全。桌面端基于 Electron 构建，支持 macOS 13.5+（Apple Silicon/Intel）与 Windows 10 22H2+/11 x64，Linux 仅支持 Hook 模式。凭证通过 Electron safeStorage、macOS Keychain 或 Windows DPAPI 加密存储，不暴露给 Web 渲染进程。项目还提供 Sessions 浏览器用于回溯每条消息与工具输入输出，追踪流程步骤到证据来源。此外内置诊断、修复、卸载、暂停采集等运维命令，支持离线执行，并提供确定性发布产物（ZIP、校验清单、Shell/PowerShell 引导脚本）以保证发布可追溯。
在 AI 编程助手快速普及的当下，Penelopa 提供了一种少见的『元层』视角——不是又一个 Copilot 竞品，而是分析你与 Codex/Claude Code 的真实交互，反向沉淀个人化的技能与检查项，形成正反馈循环。这种基于会话遥测的持续改进思路，对研究 AI 代理工程化与个性化优化的开发者具有参考价值。

该项目是一个面向 AI 编码代理（Agent Harness）的性能优化系统，旨在为 Claude Code、Codex、Opencode、Cursor 等主流代码代理工具提供统一的能力增强层。其核心理念可概括为五大支柱：Skills（技能）、Instincts（直觉）、Memory（记忆）、Security（安全）以及 Research-first Development（研究先行的开发范式）。通过为代理注入结构化的技能模块，让 AI 在面对复杂任务时能够复用最佳实践；通过直觉层帮助代理在决策路径上做出更符合工程经验的选择；通过记忆机制让代理具备跨会话的上下文延续能力，减少重复解释成本；通过安全约束防止代理执行破坏性或不合规操作；通过研究先行的开发流程，要求代理在动手编码前进行充分的信息调研与方案论证。项目定位为一个跨代理的通用优化层，而非绑定某一个具体 IDE 或模型，使团队可以在不同代理工具之间迁移统一的工作方式和治理规范。由于 README 内容有限，具体实现细节（如配置文件格式、插件机制、与各代理的集成方式）需查看仓库源码进一步确认。总体而言，该项目试图把散落在 prompt 工程、上下文管理、安全审计等环节的经验沉淀为一套可复用的规范体系。
在 AI 编码代理生态快速分化的当下，该项目尝试建立一个跨代理的通用能力标准，把 prompt 技巧、上下文记忆和安全治理沉淀为可迁移的工程实践，对希望在多套代理工具间保持一致工作方式的团队具有参考价值。

PCB Skill 是一个面向 Claude Code 与 Codex 桌面端的 Agent 技能包，用于把一个硬件想法完整推进到「可下单、可焊接、可点亮」的 PCB 成品。它通过 MCP 桥驱动 EasyEDA Pro 完成原理图、选型、布局、布线、验证等环节，并在浏览器中借助已登录会话完成打样与元件购物车的组装，最终停在预付款页面交给人工确认，Agent 本身不下单、不付款。项目围绕「性价比、好装配、免费打样」三大原则设计，覆盖概念、原理图与采购、布局与布线、制造与购买四个阶段，每个阶段都设有可复核的门禁（gate）。仓库内含 SKILL.md 主文件、按需加载的参考文档、以及独立于 EDA 的验证脚本，包括 Gerber 解析、间距扫描、钻孔清单、网络表断言与 3D 干涉检查，另附布局脚本（真实焊盘 courtyard、过孔通道）和 Specctra DSN/SES 自动布线链路等。
