HERO 反过度防御契约 ⭐ 153

一段粘贴即用的 AI 编码代理约束契约

MarkdownPrompt EngineeringAgent Config (CLAUDE.md / AGENTS.md / .cursorrules)
HERO — Anti-OverDefense 是一个针对 AI 编码代理（如 Claude Code、Codex、Cursor、GitHub Copilot、Windsurf、Gemini CLI、Antigravity 等）的行为约束方案。作者观察到这类代理常常表现出四种典型的过度防御倾向，并将其首字母缩写为 HERO：Hashing（无谓地对数据加哈希与校验）、Edge cases（沉迷于罕见边界情况）、Rubrics（用评分表、检查清单、反复自审替代真正的判断）、Overbuild（构建功能标志、迁移框架、兼容层等非必要脚手架）。项目的核心产物是一段中英文双语的 SCOPE LIMITS 契约文本，用户只需将其粘贴到代理自动加载的配置文件中（如 CLAUDE.md、AGENTS.md、.github/copilot-instructions.md、.cursorrules 等），即可约束代理在提出方案时守住范围、不做过度防御，同时保留必要的安全、迁移与审阅工作。仓库还提供 cases/ 案例目录用于在代理反驳时引用、hosts/ 说明各代理的粘贴位置、examples/ 贡献者自用配置参考。项目脱胎于同作者约 13.7k star 的 ARIS 研究项目，属于零安装、纯规则文本的轻量方案。
在 AI 编码代理普及但输出质量参差的当下，HERO 从大量实证观察中抽象出四类可命名的过度防御模式，并以最轻量的方式——一段可粘贴的规则文本——落地为跨平台通用契约。它不是又一个 MCP 或框架，而是把工程师与代理之间反复出现的争论固化为可引用的词汇和边界，兼具方法论价值和即用性，且承接自 13.7k star 的 ARIS 项目，社区背景扎实。

Vibe Coding Toolkit 是 Matheus Gomes 从真实金融科技生产项目中提炼出的 AI 辅助编程方法论合集，专为 Claude Code（也兼顾 OpenAI Codex）打造。项目的核心主张是：把「粘贴大段 prompt 碰运气」的随机流程，替换为一套结构化、可复用、经过实战验证的工作流。整个工具箱围绕三大核心构建：Superpowers 插件（作者认为最重要的一环，强制 Agent 先探索意图、再规划、最后写代码）、子代理并行编排协议（在结构层面消除文件冲突与提交竞争，而非依赖人的自律）、以及 ESLint/Biome 质量门禁（把警告提升为可追踪的迁移错误，用 lint 强制架构边界）。除此之外还有 RTK Token 代理降低会话成本、Graphify + Context7 在编码前提供代码图谱、Ponytail 与 Caveman 两种人格规范产出风格、以及基于 Claude 自带记忆系统与 Obsidian 的跨会话知识沉淀方案。仓库提供了完整的 Playbook 上手指南、CLAUDE.md 模板、可复制的 prompt 库以及 aia-harness CLI 快速初始化脚手架，配合 npm 全局安装的 Claude Code 与官方 plugin marketplace 使用。文档以葡萄牙语撰写，每个术语首次出现都会解释，面向任意水平的开发者。
这是少见的、把 AI 编程从「玩具级 demo」真正推向生产级工程实践的方法论仓库。作者坦诚方法源自 NDA 下的真实 fintech 项目，因此内容是提炼后的通用范式而非表面技巧。子代理并行编排协议和 lint 强制架构边界这类做法，在社区其他 Claude Code 资源集里几乎看不到，具有独特参考价值。对任何已经在用 Claude Code / Codex 但苦于会话失忆、Agent 越权、代码质量失控的团队，这份工具箱提供了可直接落地的骨架。

skilldoctor ⭐ 243

Agent Skills 的质量门禁与 CI 校验器

Node.js 18.18+TypeScriptnpmGitHub ActionsSARIFYAML frontmatter
skilldoctor 是面向 Agent Skills 生态的质量门禁工具，专注解决 SKILL.md 在多客户端间的规范性、安全性与可移植性问题。它与 Vercel 的 npx skills 形成互补：后者负责安装，前者负责判断该不该留。工具通过四条核心命令覆盖完整审查链路，lint 校验官方规范（name、description、目录匹配、YAML 元数据、500 行预算、references/scripts/assets 链接完整性），audit 审计危险指令（prompt injection、硬编码密钥、凭证路径、Bash(*)、curl | sh、自我修改脚本等），compat 检查 frontmatter 字段在 Claude Code、Cursor、Codex、OpenCode、Gemini CLI、GitHub Copilot 上的兼容性，scan/doctor 则枚举本地已安装的 Skills 并发现重名冲突。此外还提供 fix 自动修复、score 打分、init 脚手架、explain 规则解释等辅助命令。输出支持 human、json、sarif、markdown 四种格式，可通过 --fail-on、--ignore、--suppress 精细控制门禁策略，并支持 .skilldoctorignore 与 JSON 配置文件。项目基于 Node.js 18.18+，用 TypeScript 编写，通过 npx 直接从 GitHub 拉起，也提供官方 GitHub Action（xyiqq/skilldoctor@v0.2.3），可在 PR 里输出 annotation。规则 ID 稳定并附中英文文档，方便渐进式接入。
Agent Skills 生态正在快速铺开，但目前只有安装器（npx skills）而没有安全审查层。skilldoctor 精准切入这个空白：它不与安装器竞争，而是在 Skill 进入 ~/.codex/skills 之前提供 CI 门禁，防止 prompt injection、凭证泄漏和跨客户端不兼容的 Skill 被合入。对多 Agent 团队与 Skill 作者而言，这是一个稀缺且实用的基础设施位。

Lore ⭐ 155

编码智能体的本地会话历史归档

RustTauri 2SQLiteReactTypeScriptNode.jsCargo Workspace
Lore 是一款面向开发者的本地桌面应用，专注于浏览和搜索编码智能体（Coding Agent）的会话历史。它以只读方式读取 Claude Code 和 Codex 在本地已保存的会话文件，将这些会话与对应的代码仓库和 Git 历史关联起来，统一汇聚到一个可搜索的本地归档中，而不会包装智能体本身或修改其原始文件。项目定位清晰：不是 IDE，也不是智能体运行时或云端记忆服务，而是纯粹的本地档案库。在实现上，Lore 通过只读适配器采集 Claude Code 与 Codex 的日志，写入本地 SQLite 归档并保留 Git 证据，再通过桌面端提供搜索与浏览。它特别强调证据来源的区分，例如会话期间记录的提交与后续采集时观察到的仓库状态会被视为不同类型的证据，避免混淆。V0 版本严守隐私边界：所有数据留在本机，无账户体系、无遥测、无云数据库、无 LLM 调用。技术栈上，Lore 采用 Rust 编写核心逻辑（含 ingestion、存储、Git、搜索与安全模块），使用 Tauri 2 构建跨端桌面壳，前端基于 React 与 TypeScript，并通过 lore-ipc crate 生成 TS 绑定，工程结构清晰、构建与测试链完整。
在 AI 编码智能体井喷的当下，会话上下文和决策过程正成为新的知识资产，但 Claude Code、Codex 等工具的历史却散落各处、难以检索。Lore 抓住了这个空白点，用本地优先、隐私友好的方式为智能体提供"记忆层"，且明确克制边界（只做归档而非 runtime），工程实现（Rust + Tauri + SQLite）也符合本地桌面工具的最佳实践，值得关注其后续在多智能体整合与技能生成方向的演进。
