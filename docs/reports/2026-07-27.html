Agent Council ⭐ 202

多 AI 代理协作插件

Node.jsShell ScriptJavaScriptYAML
Agent Council 是一个为 Claude Code 和 Codex CLI 设计的多 AI 代理协作技能插件，通过编排多个已安装的 AI CLI 工具（如 Codex CLI、Gemini CLI 等）来获取不同视角的意见并合成最终结论。该项目的核心优势在于零额外 API 成本——它直接调用本地已安装的 AI CLI 工具，而非像 Karpathy 的 LLM Council 那样直接调用各个 LLM 的付费 API。工作流程分为三个阶段：首先所有配置的 AI 代理并行接收问题并独立响应；然后收集并展示各代理的回复；最后由宿主代理（默认为 Claude Code/Codex CLI）担任主席角色，综合所有意见形成最终建议。项目支持通过 npx 安装或 Claude Code 插件市场安装，安装器会自动检测可用的 CLI 工具并生成配置文件。用户可以通过 YAML 配置文件自定义理事会成员、指定主席角色、设置命令参数和显示样式。项目提供了完整的脚本工具链，支持一键执行、任务管理、进度追踪和结果清理等功能，适合需要多模型交叉验证、技术选型决策或复杂问题分析的开发场景。
该项目巧妙解决了多模型协作的成本问题，通过复用本地 CLI 订阅避免了重复 API 付费，同时提供了比 MCP 更简单的技能扩展机制。三阶段共识流程设计清晰，特别适合需要多模型交叉验证的技术决策场景，对于同时订阅多个 AI 服务的开发者具有很高的实用价值。

这是一个面向应用微观经济学实证研究的 AI 辅助技能库,为 Claude Code 和 Codex 提供 18 个独立技能模块。项目覆盖实证研究全流程:从数据获取(WRDS 连接、文献检索)、LLM 辅助分类标注(含漂移检测、一致性校验)、计量估计(事件研究、Stata/pyfixest 集成)到成果输出(LaTeX 表格、Stata 风格图表、引文校验)。核心亮点是可重现性审计工具 adversarial-empirical-review,能在隔离环境重跑整个分析流程并验证表格一致性。所有技能零依赖独立运行,可单独复制使用。技术栈以 Python 为主,集成 Stata、LaTeX、GPU 加速固定效应回归(pyfixest+CuPy)、异步 OpenAI 批处理等工具。特别关注 LLM 分类工作流的质量控制,提供标注者输入一致性检查、黄金标准边界失效诊断、模型漂移门控等五个验证模块。

BOSS Console ⭐ 198

首个开源多平台AI智能体操作台

Kotlin MultiplatformCompose MultiplatformJVMMCP (Model Context Protocol)Fluck (嵌入式浏览器)Supabase Edge Functions
BOSS Console 是首个开源的多平台 AI 智能体运行环境，为企业、科研和研究场景打造。它是一个原生 JVM 应用（非 Electron），支持多线程并发，可在笔记本到超算集群间无缝扩展。用户可接入任意 AI 编码智能体（Claude Code、Codex、Gemini、OpenCode），为其提供真实浏览器（Fluck 嵌入式浏览器）、终端（BossTerm）、代码编辑器、密钥管理和自动化能力。核心创新在于双向集成：智能体既是工作空间的使用者，也能通过 100+ MCP 工具感知和操控 BOSS 自身（标签页、终端输出、浏览器、Git 状态等），实现真正的态势感知和自主多步骤任务执行。采用 Apache-2.0 协议，基于 Kotlin Multiplatform 和 Compose Multiplatform 构建，支持 macOS、Windows、Linux（x64/ARM64）。内置细粒度权限治理（RBAC + 熔断开关）、热重载插件系统（Toolbox 应用商店）、可分享终端会话（二维码/多用户/端到端加密），并支持智能体自我演化工具。相比 Claude Desktop、Cursor、Windsurf 等闭源方案，BOSS 是唯一开源、模型无关、原生多线程的智能体平台。
BOSS Console 填补了 AI 智能体工具链的关键空白：它是唯一开源、模型无关、原生性能的多平台智能体运行环境。通过将智能体的执行环境本身暴露为 MCP 工具，实现了前所未有的态势感知和自主操控能力——智能体不仅使用工具完成任务,还能感知工作空间状态、调整自身行为,甚至在运行时演化工具。相比闭源的 Claude Desktop、Cursor 等方案,BOSS 提供完整的企业级治理(RBAC、审计)、真实浏览器自动化、跨设备终端共享等高级能力。对科研和企业用户而言,这是首个可完全自主掌控、审计和扩展的智能体基础设施,且 JVM 原生架构在高并发场景下性能远超 Electron 方案。热重载插件系统和智能体自我演化能力,使其成为探索人机协作新范式的理想平台。

Karpathy 编程准则插件 ⭐ 169

让 Claude 写出更严谨代码的行为规范

Claude Code PluginMarkdown 规范文件Cursor Rules行为约束系统
这是一个将 Andrej Karpathy 关于 LLM 编程缺陷的观察转化为可执行规范的项目。Karpathy 指出 LLM 在编写代码时常犯三类错误：静默假设（不确认需求就自行决策）、过度工程（用 1000 行实现 100 行就能解决的问题）、意外副作用（修改无关代码和注释）。该项目将这些问题提炼为四大原则：编码前思考（明确假设、呈现权衡、主动质疑）、简洁优先（只实现需求、拒绝预测性功能）、外科手术式修改（只改必要部分、保持风格一致）、目标驱动执行（定义验证标准、循环直到通过）。提供两种安装方式：作为 Claude Code 插件全局生效，或在项目根目录创建 CLAUDE.md 文件。同时兼容 Cursor 编辑器，通过 .cursor/rules 目录实现相同约束。项目强调通过结构化规则减少非平凡任务中的高成本错误，而非拖慢简单任务。适合需要 AI 辅助编程但要求严格代码质量的开发团队。
该项目首次将顶尖研究者对 LLM 编程缺陷的洞察系统化为工程实践。四大原则直接针对 AI 编程的核心痛点：Claude 等模型常因静默假设导致需求偏离、因追求灵活性导致过度设计、因上下文理解偏差引入副作用。通过强制显式推理、限制改动范围、引入验证循环，项目在保持 AI 效率的同时显著提升代码质量。对于依赖 AI 辅助的专业团队，这是首个提供标准化行为护栏的开源方案，填补了 AI 编程工具链中质量控制的空白。
