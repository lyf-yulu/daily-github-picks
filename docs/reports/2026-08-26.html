OA Design 设计语言 ⭐ 114

可被AI代理执行的开源设计语言

ReactTailwind CSS v4motion.devTypeScriptCSS shape()/color-mixNode.js CLIMarkdown Skill
oa-design 是 Open Analytics 团队将其产品级设计语言开源的产物，以三种形态交付：一份可被 AI 代理直接执行的 Skill、一组经过类型检查的组件配方（recipes），以及一个 shadcn 风格的 CLI 工具。项目的核心理念是将 Open Analytics 仪表盘中已上线的每一个色号、圆角、缓动函数与弹簧参数原封不动地抽离出来，并附带设计推理，形成一份 AI 可读、可执行的设计规范。视觉语言可概括为：白色表面配连续曲率圆角（squircle），置于安静的灰色舞台之上，使用单一墨色勾勒，由单一弹簧驱动运动。开发者可通过 `npx getopen-design add` 将组件配方注入项目，或将 Skill 目录复制到 `.claude/skills` 供 Claude Code 调用，也可直接引用编译后的 `DESIGN-SKILL.md` 让 Cursor、Codex 等任意代理遵循。仓库包含 12 个组件配方（Tab Bar、Toast、Modal、多步对话框、骨架屏、头部变形等），配套 `_root.css` token 块、七种弹簧运动词表以及排版、动效、文案指南。构建脚本 `build/sync.mjs` 会把 `components/` 中通过 `npm run typecheck` 的源码注入 MD 配方，保证文档中的代码即产品代码。技术栈基于 React + Tailwind v4 + motion 库，但产物本质是纯 CSS 数值与弹簧常量，可移植到任意框架。采用 MIT 协议，运行时零依赖。
这是 AI Coding 时代设计系统交付方式的一次范式实验：不再把设计规范做成 Figma 文件或组件库，而是编译成 AI 代理可执行的 Skill 文件，让 Claude Code、Cursor 在生成 UI 时自动遵循真实产品的动效与视觉参数。它把'设计规范'从人类阅读物升级为机器可执行的工程契约，并示范了 recipes + skill + CLI 三态从单一源码同步的仓库结构，对希望向 AI 代理暴露自有设计语言的团队具有直接参考价值。

swissdevjobs-cli 是一个零依赖的 Python 命令行工具，将 7 个国家、8 个招聘板块（涵盖瑞士、德国、英国、美加、荷兰、法国的 devitjobs 系列 IT 招聘站，以及瑞士全行业站 jobs.ch 与 jobup.ch）整合到统一的终端界面中，可检索约 4700 个强制公开薪资的技术岗位以及约 5 万个瑞士综合岗位。核心特色是把薪资作为一等过滤条件（--min-salary），并通过解析 MongoDB ObjectId 还原岗位的真实创建时间，避免被平台的“刷新日期”误导。工具使用本地 SQLite 记录已投递岗位，自动从列表中隐藏重复项。除 CLI 外还内置 MCP 服务器和 Claude Code 插件，所有命令均支持 --json 输出，可被 LLM Agent 直接驱动，实现自然语言搜索、筛选与投递。仅依赖 Python 3.9+ 标准库，无任何第三方包，规避供应链风险。

mediagen ⭐ 56

Node.js 20.11+npm/npxTypeScript/JavaScript CLIMCP (Model Context Protocol)Google Gemini APIOpenAI APIKie AI API
mediagen 是一款为 Claude Code 等编码智能体（coding agent）设计的图像与视频生成技能（skill），通过统一的 CLI 与 MCP 服务器封装 Google Gemini、OpenAI 和 Kie AI 三大提供商，让智能体只需一次安装即可调用约 30 余种模型完成图像生成、视频生成和媒体编辑。项目内置提示词编写指导，可将模糊的自然语言需求扩写为包含主体、构图、光线、镜头与材质的完整描述；同时具备提供商智能路由能力，能根据宽高比、视频支持度与 API Key 可用性自动挑选最合适的模型（例如 21:9 走 Gemini、OpenAI 无法输出 16:9 时自动跳过）。它还遵循欧盟 AI 法案（EU AI Act）要求，可对 AI 生成内容进行可见与不可见标记。配置层面提供 init 向导、doctor 健康检查、环境变量与配置文件多层解析，并在 shadowed 值、错误码与恢复动作上做了细致处理，兼顾交互式使用与 CI 场景。所有错误均携带机器可读代码，便于智能体自主恢复。

Cybermes ⭐ 549

自主化攻击性安全与漏洞赏金自动化框架

Go 1.22+Python 3.11+Model Context Protocol (MCP)JSON-RPC 2.0DockerPowerShellsubfinder / httpx / katana / ffuf / nuclei / sqlmap
Cybermes 是一款面向授权漏洞赏金、红队演练与渗透研究的自主化攻击性安全自动化框架，基于 Hermes 智能代理进行推理编排，并结合多模型 LLM 协同工作。项目通过原生 Go 编写的高性能工具链（如流式过滤器 smart_pipe、凭证扫描 secret_scan、离线知识检索 search_knowledge 和报告聚合器 aggregate_reports）解决传统 AI 辅助安全测试中的上下文噪声与令牌浪费问题，仅将高价值端点、状态码与敏感信息流式传递给 LLM。框架内置 200+ 模块化攻击 SOP 剧本，覆盖 API 安全（IDOR/BOLA、JWT、BPLA）、Web 漏洞（SSRF、XSS、SQLi、竞态条件）与云配置错误等场景，并集成 subfinder、httpx、katana、ffuf、nuclei、sqlmap 等主流侦察与利用工具。Cybermes 通过原生 Go 实现的 MCP（Model Context Protocol）服务器 cybermes-mcp 直接对接 Cursor、Claude Desktop、Windsurf、VS Code/Cline 等 AI 编码环境，支持一键 npx 自动安装。其核心创新在于「零误报 PoC 验证门」机制，要求生成独立、非破坏性的 Python 验证脚本并附带原始 HTTP 证据，避免推测性告警。最终输出包含 SUMMARY.md、metadata.json、交互式 HTML 与 PDF 的结构化报告，并支持 Windows、Linux、macOS 及 Docker 全平台部署。
Cybermes 将 AI 代理与传统攻击性安全工具链深度融合，通过 MCP 协议标准化 LLM 与安全工具的交互方式，并以原生 Go 实现解决 LLM 上下文膨胀这一实际痛点。其「零误报验证门」设计弥补了当前 AI 安全助手普遍存在的幻觉与推测性告警缺陷，使自主化红队工作流真正具备可复现性与工程落地价值，是 AI 驱动攻击性安全领域少见的兼顾性能、协议标准化与验证严谨性的开源项目。

LLM-RAG-记忆-AI智能体实践教程 ⭐ 118

土耳其AI学院LLM与RAG实战教程

PythonLangChainlangchain-google-genailangchain-communitylangchain-text-splittersGoogle Gemini APIFAISSpython-dotenv
该仓库是土耳其人工智能学院（Türkiye Yapay Zeka Akademisi）发布的一套面向初学者的大语言模型（LLM）实践教程，围绕三个循序渐进的主题展开：LLM 基础调用、RAG（检索增强生成）以及 AI Agent（智能体）。项目采用 Python 虚拟环境进行隔离，通过 LangChain 框架对接 Google Gemini 模型，并使用 python-dotenv 管理 API 密钥。第一部分讲解如何搭建虚拟环境、安装 langchain 与 langchain-google-genai 等基础依赖，并完成首次 Gemini API 调用。第二部分聚焦 RAG 场景，以军用标准（MIL-STD）文档为语料，划分为 mil_std_document.py（文档生成）、create_vector_db.py（向量数据库构建）与 rag.py（检索问答）三个模块，引入 langchain-community、langchain-text-splitters 和 faiss-cpu 实现文本切分与向量检索。第三部分预留给 AI Agent 相关内容。整体项目结构清晰，命令与依赖列表明确，适合作为中小型团队或学员学习 LangChain 生态、Gemini 接入与本地向量检索的入门实践模板，也可作为构建领域文档问答系统（如军规、标准手册）的参考骨架。
