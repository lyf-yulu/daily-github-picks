HERO 反过度防御规则 ⭐ 184

一段贴入配置的AI编码代理防过度防御契约

MarkdownPrompt EngineeringClaude CodeCodexCursorGitHub CopilotWindsurfGemini CLI
HERO（Anti-OverDefense）是一个针对 AI 编码代理'过度防御'行为的反制方案。作者将编码代理在实际工作中偏离目标、过度自我保护的四种典型形态命名为 HERO：Hashing（无意义的哈希/校验）、Edge cases（对不可达边界情况的执着）、Rubrics（用打分表和复核循环替代判断）、Overbuild（防御性脚手架的过度堆砌）。项目定位是一份可直接粘贴到代理配置文件（如 CLAUDE.md、AGENTS.md、.github/copilot-instructions.md、.cursorrules）中的行为契约，兼容 Claude Code、Codex、Antigravity、Cursor、GitHub Copilot、Windsurf、Gemini CLI 等主流工具，无需安装任何软件。核心内容包括 RULES.md（中英文契约正文，含六条规则与'简版'）、cases/（真实观察到的过度防御案例目录，用于在代理反驳时反引）、hosts/（各代理粘贴位置说明）、examples/（贡献者在自己项目中的 AGENTS.md/CLAUDE.md 实例）。规则强调：非安全研究项目默认协作场景、禁止无用哈希、禁止为不存在的情况添加迁移框架和兼容层、边界情况必须在项目实际用途中可达、需要判断的地方就判断而非用打分表替代，同时保留用户主动要求的安全/迁移/审查工作。该项目脱胎于 ARIS（约 13.7k★）的实践观察，是对 AI 代理行为模式的经验性归纳。
HERO 抓住了当前 AI 编码代理最真实的痛点之一：代理为了'不被指责'而不断堆砌哈希、边界检查、评分表和防御层，最终功能反而没写完。它没有走复杂工具链路线，而是用一份可粘贴的自然语言契约给出解法，覆盖几乎所有主流编码代理，实用性和传播成本极低。同时项目坦诚说明局限（长会话中规则会被稀释、需要重新粘贴），并区分'真实发现'与'过度防御'，避免走向另一极端，这种克制在同类 prompt 项目中比较少见。

生产级 AI 编码工作流工具包

Vibe Coding Toolkit 是一套由 Matheus Gomes 从真实生产环境（某金融科技 NDA 项目）中提炼、并已通用化的 AI 辅助编码工作流工具包，主要面向 Claude Code，也兼顾 OpenAI Codex。项目的核心理念是把 AI 编码从『粘贴大提示词碰运气』转变为一套可复现、可测试的结构化流程，让 AI 代理真正成为团队的一员，而不是需要时刻盯梢的『多动症实习生』。工具包围绕六大支柱展开：Superpowers 插件（作者主推的核心，强制代理先探索意图、规划，再动手写代码）；子代理并行波次编排协议（在结构层面消除文件冲突和提交竞争，而非依赖纪律约束）；ESLint/Biome 质量门禁（把警告提升为可追踪的错误迁移，用 lint 强制架构边界）；Graphify + Context7 代码图谱与上下文注入；RTK Token 代理（降低会话成本）；Ponytail/Caveman 人格控制；以及基于 Claude 原生记忆和 Obsidian 的跨会话记忆系统。仓库以 Playbook 式的完整上手指南、CLAUDE.md 模板、多代理评审流程以及可直接复制的提示词为交付形式。
这套工具包的价值不在于代码本身，而在于把一个真实生产项目中长期打磨出的 AI 协作方法论完整拆解出来：子代理并行波次编排在作者调研的第三方合集中未曾出现，属于原创方法；把 lint 警告作为架构迁移追踪工具的思路也超越了大多数 AI 编码模板的『装好就跑』水平。对于希望把 Claude Code 从玩具升级为生产级团队成员的开发者，这是少见的、有明确落地路径且已经过实战验证的参考实现。

AI 求职助手 ⭐ 218 (+218 today)

在 AI CLI 中本地化运行的智能求职助手

Claude CodeCodex CLIOpenCodeAntigravityPrompt EngineeringMarkdown
该项目是一个开源的 AI 驱动求职工具，定位为运行在开发者本地 AI 编码 CLI（如 Claude Code、Codex、OpenCode、Antigravity 等）中的求职工作流助手。它的核心思路是把求职流程拆解为可自动化的几个阶段：扫描各大招聘门户抓取岗位信息、使用结构化的 A-F 六维评分标准对岗位进行系统性评估并折算为 1.0 至 5.0 的匹配分数、根据具体岗位定制化调整简历（CV）、以及跟踪申请状态。通过将这些能力沉淀为可复用的提示词与命令，用户可以在自己熟悉的 AI CLI 环境中一键触发，避免了传统 SaaS 求职平台的数据外泄风险和订阅费用。项目主打本地优先与工具无关性，理论上兼容任意支持自定义指令的 AI 编码 CLI，让求职者既能享受大模型的语义理解与文本生成能力，又能完全掌控自己的简历、岗位数据和评估记录。A-F 评分维度以结构化方式规避了大模型给分随意化的问题，让不同岗位之间的匹配度可横向比较，从而帮助求职者聚焦高价值机会。整体上它把 AI CLI 从纯编码工具扩展到了个人生产力场景，是 agentic workflow 与本地化 AI 落地的一个有趣样本。
该项目由 GitHub Sponsors 账户维护，代表了 AI CLI 生态从代码场景向个人事务扩展的新方向。它把结构化评分、简历定制、申请跟踪等原本属于付费 SaaS 的能力，转化为可在本地 AI CLI 中运行的开源工作流，兼顾了隐私、灵活性与低成本，是 agentic 应用落地个人生产力的典型范式。
