Bang Motion ⭐ 116

让 AI 智能体在浏览器里做真动效

HTML/CSS/JavaScriptGSAP 动画库WebGLAgent Skills 规范（SKILL.md）Node.js + Puppeteer（可选帧截取）ffmpeg（可选 MP4 导出）
Bang Motion 是一个面向 AI 编程智能体（Claude Code、Codex、Gemini CLI、Cursor 等）的 Agent Skill，专门用于在浏览器中生成运动图形作品，包括产品开场、宣传片、频道 ID、动态字幕、下三分之一字幕以及五种解说视频风格。最终产物是单个 index.html 文件，双击即可自动播放、循环，无播放器控件，也无需 npm install。项目的核心思路是：AI 通常把'视频'做成一页页幻灯片，Bang Motion 则把资深动效设计师的经验编码成智能体可在自身代码中自校验的结构化规则——统一世界观、真实的镜头运动、贯穿场景的主体、嵌入场景内的数据可视化等。它通过'菜单式选择'（八种风格方向、十一种背景运动、六种背景表面、九种转场、六种高亮形状）避免智能体总是选默认最廉价的方案，并强制项目间不得重复。工作流上，智能体先产出风格纲要（主题、品牌色、字体、背景语言、动效签名），再交付 index.html 与配音脚本，用户录制或生成语音后回传，时间轴会自动对齐到人声。技术上基于 GSAP 与 CDN 字体，时间轴是时间的纯函数，支持逐帧精确导出；配套 puppeteer 截图与 ffmpeg 导出 MP4 的可选脚本，还提供纯浏览器的停顿检测工具。
它示范了 Agent Skill 的一种高级用法——不是给智能体加工具，而是给它'审美与结构纪律'。通过菜单式选择、跨项目防重复、代码内自检等机制，把'动效设计师的品味'转化为智能体可执行的硬约束，解决了 AI 生成视觉内容普遍'像幻灯片'的通病。同时以单文件 index.html 交付、CDN 依赖、可选导出链路的极简架构，兼顾了可玩性和工程化，是 Agent Skill 生态中少见的创意生产范例。

Penelopa.ai ⭐ 105

AI 编程助手的持续改进平台

Node.js 24.20.0ElectronTypeScriptPlaywrightShell/PowerShell 安装脚本macOS Keychain / Windows DPAPI
Penelopa.ai 是一款面向 AI 编程代理（Codex 与 Claude Code）的持续改进工具，其定位是通过分析真实的编程会话来提炼可复用的工作流模式。项目通过在用户本地的 Codex 或 Claude Code 中注入 Stop 与 SessionEnd 钩子，采集实际编码会话事件，识别重复出现的工作流模式，并将其转化为可复用的技能（skills）、检查项（checks）、提示词（prompts）与改进建议，最终在个人网页仪表盘和桌面客户端中呈现分析报告。安装脚本会下载经过校验的私有 Node/npm 运行时，无需系统包管理器、Git、Python 或 Homebrew 等依赖，也不修改全局 PATH，桌面端基于 Electron 构建，支持 macOS 13.5+（Apple Silicon 与 Intel）与 Windows 10 22H2+/11 x64，Linux x64/arm64 仅支持钩子模式。凭证使用 Electron safeStorage、Keychain 或 DPAPI 保护，令牌不暴露给 Web 渲染进程，失败上传会本地排队并在钩子事件触发时重试。项目还提供 --diagnose、--repair、--uninstall 等运维命令，以及基于 Playwright 的 Web 单元与视觉回归测试、桌面资产哈希校验与确定性发布流程，形成一套完整的本地采集与云端分析闭环。
Penelopa.ai 切中了当下 AI 编码代理缺乏反馈闭环的痛点，把日常会话变成可迭代的工作流资产，是 agent 持续学习方向上少见的工程化落地。其安装与发布链路在安全性上极为克制：私有运行时隔离、忽略 npm 生命周期脚本、确定性源码 ZIP 与校验和清单、明确区分 ad-hoc 签名与受信发布，值得作为跨平台桌面工具分发的参考样本。

PCB Skill ⭐ 78

从硬件想法到可下单PCB的Agent技能

Claude Code / Codex Agent SkillMCP (Model Context Protocol)EasyEDA ProPython (脚本工具链)Specctra DSN/SES 自动布线Gerber 解析与几何验证浏览器 Agent 扩展
PCB Skill 是一个面向硬件开发的 Agent 技能包，运行于 Claude Code 或 Codex 桌面端，通过 MCP 协议驱动 EasyEDA Pro，把一个硬件想法一路推进到可下单、可焊接、可上电的实体 PCB。工作流覆盖概念定义、原理图与选型、布局布线、验证以及采购下单前的最后一步，Agent 会在浏览器中把购物车准备到付款页面前一步交由人工点击，绝不自动付款。项目秉持三大原则：性价比（每颗器件从实时页面取价并抵扣现有库存）、好装配（禁用底部端子封装，规划焊接顺序）、免费 PCB（从第一张草图起就贴合免费打样规格）。技术亮点包括：独立于 EDA 工具的 Gerber 解析与净表断言、Specctra DSN/SES 自动布线链路与四态看门狗、基于真实焊盘生成 courtyard、每阶段的对抗性只读评审等。仓库同时提供 macOS/Windows 自动审批脚本与真实项目的成本复盘案例。
