给 AI 编码 agent 用的技能集合

Node.js (≥18)JavaScript (ES Modules, .mjs)Claude Code SkillsCodex CLIShell 脚本Mermaid/Markdown 文档
shuohao-skills 是一个面向 AI 编码 agent 的 skill 集合仓库，同时兼容 Claude Code 和 codex 两大主流 AI 编码环境。仓库当前主打 skill 是 novel-characters，它能把一整本小说自动拆解为完整的角色设定集，包括人物画像、卡通形象提示词、音色提示词以及角色三视图设定图，最终产出一份可视化的角色设定报告，报告语言和出图风格可自由配置。项目在工程约定上强调自包含与零依赖：每个 skill 独立成目录，可单独拷走使用，脚本只依赖 Node 标准库，无需 npm install，也不需要任何 API key，直接消耗用户当前 AI 会话的模型额度。安装脚本会自动识别本机安装的是 Claude Code 还是 codex，通过软链方式接入，git pull 后即刻生效，无需重装，同时支持指定 skill、指定平台以及一键卸载。仓库为每个 skill 强制要求配备 SKILL.md 工作流说明与 scripts/selftest.mjs 自测脚本，自测不调用模型、不消耗额度，运行秒级完成，覆盖全部确定性逻辑，用极轻量方式替代 CI。出图能力可选，依赖 codex CLI 内置的 imagegen，没有也不影响其余文本产出。整体呈现出面向实战短剧与内容创作的工具化思路。
在 AI agent skill 生态尚未标准化的当下，本仓库用一套极简的目录约定同时打通 Claude Code 与 codex 两条生态，且完全零依赖、零 API key，是研究可移植 AI skill 打包方式的优秀参考。novel-characters 面向 AI 短剧和内容创作这一正在爆发的场景，把 LLM 从写文本推进到出角色设定图的完整流水线，实用性和示范性兼具。

SkillForge ⭐ 106

AI Coding Agent 的技能版 npm

RustTypeScriptNode.js 22+pnpmFastifySQLiteNext.js 14Tailwind CSSEd25519 / minisigMCP 协议Ollama / OpenAI API
SkillForge 是一个面向 AI Coding Agent（Claude Code、Cursor、Codex、Gemini CLI 等）的本地优先技能运行时，定位为『技能版 npm』，模型无关、MCP 原生。它把 Agent 能力抽象为可校验、可组合、可分发的独立技能单元，每个技能通过 skill.yml 描述清单、SKILL.md 说明用法、eval.md 定义评测基线，并以 allow.read_paths、write_paths、net_hosts 明确执行边界。项目当前处于 Phase 1 MVP，Rust 编写的 core 提供 run/serve/validate/eval 命令，实现 Plan→Act→Observe→Reflect 循环、Token 预算截断、白名单沙箱以及 macOS Seatbelt 平台沙箱自动接入，并通过 HTTP 暴露 MCP 的 initialize/tools/list/tools/call 接口。分发侧提供 TypeScript 三件套：本地 CLI 支持多源聚合、Bearer Token 鉴权、Scope RBAC 与 Ed25519 minisig 签名发布链；registry-service 基于 Fastify + SQLite + 文件存储抽象对齐 /v1/skills 协议并带完整审计；registry-web 用 Next.js 14 + Tailwind 提供 Shadcn 风格 UI，覆盖技能列表、详情、版本对比与审计日志。模型侧同时接入 Ollama 与 OpenAI 兼容 API，内置 fix-ci、grep-ts、doc-gen 三个示例技能。
在 Agent 生态里，多数『技能库』还停留在 prompt 片段和仓库模板，SkillForge 少见地把包管理器的工程范式（清单、版本、签名、权限、审计、评测门禁）完整搬到 Agent 技能上，同时坚持本地优先与 MCP 原生。它既能被 Claude Code/Cursor 直接接入，又提供了从 CLI 到 Web UI 的完整分发闭环，是观察 Agent 基础设施走向标准化与可治理的一个有代表性的样本。

长时程智能体执行框架 LongHorizon-Harness ⭐ 411

让 AI 智能体持续可靠完成长时程复杂任务

Python ≥3.10Claude CodeCodex CLIOpenClawAgentAdapter 插件机制可插拔 Environment 协议计算机使用（Computer-Use）插件体系
LongHorizon-Harness 是由高德地图机器学习团队（AMAP-ML）开源的长时程（Long-Horizon）计算机使用智能体执行框架，专注于让 AI Agent 在真实桌面与命令行环境中连续工作数十小时，完成跨应用、跨轮次的复杂任务。项目的核心定位并非训练新模型或替代现有 Agent，而是在 Claude Code、Codex CLI 等主流智能体之上构建一层执行、状态管理与结果验证系统，解决长任务中普遍存在的上下文漂移、进度丢失和结果不可信问题。框架采用三角色分离设计：Manager 负责维护原始目标与已验证进度，Executor 每轮以全新上下文专注单一子任务，Auditor 独立审计文件、接口、日志与测试，只有通过独立验证的结果才会写入持久化任务状态，从而实现新鲜上下文执行、可恢复进度、独立审计和可验证交付。它同时支持 GUI 桌面操作（浏览器、Office、设计与 3D 工具）与 CLI 命令行开发（编码、脚本、依赖安装、系统调试），并通过轻量 AgentAdapter 与可插拔 Environment 协议兼容 Claude、GPT、Qwen 等不同模型，允许三个角色各自选用不同后端以平衡质量、速度与成本。项目已在 WeaveBench、OSWorld 2.0、Terminal-Bench 2.1 等基准的数百个真实任务上验证效果，覆盖 Web 前端、数据分析、运维调试、设计图像、游戏交互、文档演示、空间推理等十余个领域。
长时程 Agent 是 2025-2026 年智能体研究最难啃的骨头，绝大多数框架仍停留在单轮 Demo。LongHorizon-Harness 不是又一个新模型，而是把「谁来规划、谁来执行、谁来验证」拆开，用独立审计守住持久化状态这条底线，思路更贴近工程可用性；配套在 OSWorld 2.0、Terminal-Bench 2.1 等基准上的真实评测和登顶 Hugging Face Daily Papers 周榜的关注度，使它成为想把 Claude Code / Codex 推向生产级长任务的开发者值得优先考察的开源方案。

Agentic Documents Assistant 是一个基于大语言模型的智能知识管理与文档问答平台，面向企业级业务文档分析场景。项目采用 Agentic AI 架构，将 RAG 语义检索、结构化实体抽取与 SQL 分析推理相结合，支持三类问题的自动化处理：一是基于向量检索直接回答事实性问题；二是通过将自然语言转换为 SQL 查询、在结构化实体数据库上执行来解答分析型问题（例如未来三个月到期的合同列表）；三是借助 ReAct（Reason and Act）范式的 LLM 智能体，在语义搜索、SQL 查询与外部工具之间自主决策，完成多步骤复杂推理任务。项目包含文档摄取与批处理数据管道、向量存储与检索、实体抽取与结构化数据存储、后端服务，以及基于 Next.js 的前端聊天应用，具备鉴权与安全通信能力，形成完整的端到端解决方案。
