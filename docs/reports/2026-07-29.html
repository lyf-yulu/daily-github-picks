Agent Harness 性能优化系统 ⭐ 636 (+636 today)

为 AI 编码智能体注入技能与记忆

Markdown / Prompt EngineeringClaude Code SkillsAgent ConfigurationMemory Systems
该仓库定位为面向 AI 编码智能体的「性能优化系统」（Agent Harness Performance Optimization System），目标是为 Claude Code、Codex、Opencode、Cursor 等主流 AI 编程助手提供一套通用的能力增强框架。项目通过五大核心维度提升 Agent 的工作表现：Skills（可复用的技能模块）、Instincts（内建的行为直觉与默认判断规则）、Memory（跨会话的上下文记忆机制）、Security（安全约束与守护策略）以及 Research-first Development（以研究先行的开发方法论）。这种设计尝试解决当前 AI 编码助手常见的痛点——缺乏长期记忆、行动前调研不足、安全边界模糊、能力零散不可复用等问题。由于目前仅有仓库描述而无详细 README，项目具体实现形态（是配置集、Prompt 库、还是运行时中间件）尚需进一步查阅源码确认，但从命名与定位可推断其是一种跨编辑器、跨 Agent 平台通用的能力注入层，帮助开发者以统一方式管理和分发 Agent 的行为规范与知识资产。作为 GitHub Sponsors 页面下的项目，它也代表了社区对 Agent 工程化实践的持续投入方向。
在 AI 编码助手爆发式增长的当下，如何让 Agent 从「一次性生成」进化为「可持续协作」是关键课题。该项目正切中这一趋势，提出跨平台通用的 Harness 层设计，将技能、记忆、安全等要素模块化，具备成为 Agent 工程化标准实践的潜力，值得关注其后续演进。

开放图像提示词档案库 ⭐ 126

本地优先的可溯源视觉提示词库

Python 3 (uv 管理)Node.js 20.19+ / 22.12+SQLite (只读 immutable 模式 + FTS 全文索引)前端 Vite (5173 端口)Docker (Node 22 + Python 3 运行时)GitHub Releases 作为数据资产 CDN
Open Image Prompts 是一个开放、本地优先（local-first）的视觉提示词档案项目，致力于解决 AI 绘画场景中提示词与生成图像之间缺乏可追溯参考的问题。项目提供了两个可安装的 Agent Skills：img-gen-taste 负责将粗略需求转化为清晰的艺术方向；img-gen-prompts 则用于检索可溯源的提示词-图像参照对，并在本地打开对比画廊。公开数据集规模可观，包含 14,028 条源提示词、24,305 张图像、28,056 条双语翻译、163,135 个活跃的 v2 提示词标签，以及一个包含 185 个视觉标签的封闭分类体系。项目在工程层面做了精心设计：代码仓库本身保持精简，只跟踪应用代码、前端、API、Skills、分类法与轻量索引；而 SQLite 数据库（约 80MB）与按月打包的图像资产（合计约 4.3GB）通过 GitHub Releases 分发，并使用 sha256 校验完整性。用户可通过 start.sh / start.bat 一键启动，脚本会自动安装 uv、创建 Python 环境、拉取数据集并启动前后端服务；也支持通过 Docker 部署，构建阶段会执行数据校验、测试、lint 与生产构建。API 与 Skill 以只读不可变模式打开 SQLite，默认绑定 127.0.0.1 回环地址，绝不启动标注任务，安全边界清晰。
该项目在 AI 提示词生态中提供了少见的『开放 + 可溯源 + 本地优先』三合一方案：数据集不是黑盒，而是通过公开的 SQLite 与清单文件可完整校验；提示词与图像的对应关系可追溯，避免了社区中常见的『无图或图不对版』问题；Agent Skills 的形式让它天然可被 Claude 等编码代理直接调用，为 AI 绘画工作流提供了标准化的参考数据层。工程实践上的 Release 分发、sha256 校验、只读运行时、回环绑定等细节也体现了对可复现性与安全性的重视，适合作为构建垂直提示词库的参考范式。
