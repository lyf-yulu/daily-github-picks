sepia ⭐ 1,233

跨 Agent 通用的去 AI 味写作技能包

MarkdownAgent Skills 规范Skills CLIClaude Code PluginCodex PluginGrok Build PluginAntigravity Plugin
sepia 是一个基于 Agent Skills 标准的可移植写作技能包，专注于消除 AI 生成文本的痕迹（De-AI writing）。与主流的仅修改词汇和句法的「humanizer」不同，sepia 依据 StoryScope（arXiv:2604.03136，基于 61,608 篇故事和 5 个前沿 LLM 的实验）等 11 项研究成果，指出 AI 文本的破绽主要在叙事结构层面（如叙述者直接解释主题、单线因果、情感仅以身体感受呈现、缺乏现实指涉等），因此提出「叙事架构—话语流—表层风格」三层修改协议，配合 30 项诊断量规和 Claude、GPT、Gemini、DeepSeek、Kimi 五种模型的专属指纹修正。对于专业文本（发布说明、PR 回复、事故复盘、工单、技术文章），则按场景匹配独立规则集。核心原则是「向人类分布校准，而非反转 AI 分布」，每次仅选取 3–5 条修改动作以避免形成新指纹。项目提供 write（写作）、review（仅诊断）、refactor（最小修改）、recreate（重写）四种操作。发行形态上，一份 SKILL.md 通过 Skills CLI 可安装到 77+ 个 Agent，同时为 Claude Code、Codex、Grok Build、Antigravity 提供原生插件封装。v0.4.0 起支持叠加外部 voice/style 技能，实现风格与架构的组合。
sepia 把 AI 味识别与消除从「改词换句」的传统路径推进到叙事结构层面，直接对应学术研究中真正难以掩盖的 AI 特征；同时以 Agent Skills 标准为载体，实现跨 77+ Agent 的一次编写、多处部署，兼具研究严谨性与工程通用性，是提示词工程与 Agent 生态融合的典型样本。

Agent Harness 性能优化系统 ⭐ 512 (+512 today)

面向 AI 编程代理的性能优化框架

Claude CodeCodexOpencodeCursorAgent HarnessPrompt Engineering
该项目是一个面向 AI 编程代理（Agent）的性能优化系统，旨在为 Claude Code、Codex、Opencode、Cursor 等主流 AI 编码工具提供统一的能力增强层。项目核心理念是通过五大支柱来提升代理的执行质量：技能（Skills）用于封装可复用的专业能力，直觉（Instincts）帮助代理在模糊场景下做出更合理的判断，记忆（Memory）让代理在跨会话与跨任务时保持上下文一致性，安全（Security）确保代理在执行敏感操作前具备防护与审计能力，研究优先（Research-first）则强调在编码前先进行充分的信息收集与验证，避免盲目生成代码。仓库以 sponsors 形式发布，说明其可能采用付费或赞助制订阅模式，面向专业开发者与团队用户。由于 README 内容极为精简，具体实现细节、配置方式、支持平台的适配层以及扩展机制尚不明确，但从定位来看，它试图成为一个跨 IDE、跨代理的通用增强层，把当前碎片化的提示工程、上下文管理与安全策略沉淀为可复用的工程化产物。对于希望在多个 AI 编码工具间保持一致工作流的团队，这类 harness 层具备较高的参考价值。
在 AI 编码代理生态高度碎片化的当下，该项目尝试提供一个统一的性能优化 harness，将技能封装、记忆管理、安全审计与研究优先方法论沉淀为跨工具的通用层，对于追求稳定工程化 AI 工作流的团队具有前瞻性价值。

Forward Implementation First ⭐ 154

让编码智能体先交付、后验证的技能规则

Markdown (Agent Skill 格式)YAML frontmatterShell (install.sh)Agent Skills 规范 (agentskills.io)适配 Claude Code / Codex 等编码智能体
Forward Implementation First 是一个面向编码智能体（如 Claude Code、Codex 等）的 Agent Skill，用一份约 150 行的 Markdown 规则文件，解决长流水线中智能体沉迷于自造「行政事务」——哈希、锁文件、执行回执、认证标记、进度元数据——而停止交付真实产出的顽固失败模式。它要求智能体在每次动作前将其归类为三类之一：语义实现（构建生产者、消费者、适配器、模式或最终产出）、聚焦验证（对变更依赖锥进行行为、模式、计数、样本、守恒、一致性、非截断、时耗与内存的测量）、行政簿记（哈希、锁、回执、仪表盘、认证标记等）。前两类照做，第三类默认跳过，除非用户明确要求或该产物本身就是产品的一部分；若第三类在不保护正确性的情况下阻塞流程，则直接删除该依赖。同时该技能坚持保留真正的证据：产品自身的完整性校验、输入与修订标识、断言结果的测试与基准、覆盖与后果的区分。它还定义了「前向游标规则」——只有输入语义变化、目标修订变化、输出畸形、观测运行反证或依赖锥要求时才回放阶段，缺失或过期的元数据不构成回滚理由。并行部分只保留调度中立的不变式（唯一写者、消费前验证、前向推进不等所有 worker、禁造忙工作），把调度策略留给运行时。项目以纯 Markdown + Shell 安装脚本形式分发，模型无关、工具无关、领域无关。
该项目精准命中当下长时运行编码智能体最普遍且最昂贵的失败模式——把行政元数据当作正确性代理，从而在无产出的簿记循环中烧掉大量 token 与时间。它不是又一条「加快速度」的模糊提示，而是给出可执行的分类决策、明确的证据边界与前向游标规则，并克制地拒绝越权做调度器，工程判断成熟。仅 150 行 Markdown、模型/工具/领域无关，安装成本近乎为零，却能直接改变 agent 的行为轨迹，对任何运行有状态流水线或多智能体协作的团队都具备高杠杆价值。

useAgent ⭐ 151

开源AI同事：交付成品的智能体平台

Bun (运行时)TypeScriptPostgres 16 + pgvectorDaytona / CubeSandbox (沙箱)noVNC (桌面可视化)Slack API / GitHub AppTerraform (Hetzner 参考部署)Docker
useAgent 是一个开源的团队 AI 同事平台（AGPL-3.0，处于 Alpha 阶段），将 Claude Code、Codex、OpenCode 等主流编码/通用智能体统一为具备独立云端计算机、企业工具与上下文的"数字员工"，直接交付可用成品——网站、幻灯片、电子表格、研究报告、经过测试的 PR，而不仅仅是回答。其核心设计有三点：一是引擎即插件，所有智能体通过引擎适配器讲同一套规范事件契约，可自由替换而不丢失线程、产物与记忆；二是运行即事件日志，Postgres 作为唯一真相源，每次运行都是可重放、可审计的事件流，后端重启后仍能恢复并接管在跑会话；三是凭据零下沉，代理的沙箱工作站（Daytona 或自托管 CubeSandbox，带 noVNC 桌面与 MP4 录制）完全隔离，所有集成通过受信网关以类型化工具形式暴露，密钥仅存于控制面。平台原生支持 Slack（@提及触发、线程审批）、GitHub App、Gmail/Linear/Notion/HubSpot 连接器，可从 GitHub 导入 SKILL.md 作为版本化技能，附带知识库、团队记忆、人机在环审批卡，以及 DOCX/XLSX/PPTX/PDF 原生带修订的产物编辑。可在任意 Linux 主机上自托管，提供 Hetzner Terraform 参考与 deploy-app.sh 一键脚本。
useAgent 把当下最热的编码智能体（Claude Code、Codex、OpenCode）从"聊天回复"抽象成了可交付成品的企业级同事，并以事件溯源 + 隔离沙箱 + 受信网关三件套解决了 Agent 落地生产的关键痛点：可审计、可恢复、凭据安全。相比多数只做 Chat 封装的 Agent 项目，它给出了一套完整的控制面/数据面架构，且完全开源可自托管（AGPL），对希望在企业内部规模化运行 AI 智能体的团队具有很强的参考与落地价值。
