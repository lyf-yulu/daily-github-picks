shuohao-skills ⭐ 501

AI 编码 agent 的 skill 集合

Node.js (≥18, 标准库)Shell (install.sh)Claude Code Skillscodex CLI ($imagegen)Markdown (SKILL.md 工作流)
shuohao-skills 是一个面向 AI 编码 agent 的 skill 集合仓库，可同时在 Claude Code 和 codex 两种 CLI 环境中运行，目标是把常见的复杂创作类任务封装成可复用的工作流。当前仓库首发的核心 skill 是 novel-characters，它能把一本完整的小说自动拆解为一份「角色设定集」，产出包括人物画像、卡通形象提示词、音色提示词以及角色三视图（turnaround）等内容，报告语言与出图风格均可配置，最终以图文报告形式呈现。项目在工程约定上非常克制：每个 skill 一个自包含目录，包含给 agent 读的 SKILL.md 工作流、给人看的 README、零依赖的 Node 脚本（scripts）、按需加载的 references、可作测试夹具的 examples 和截图 assets。安装通过 install.sh 脚本自动检测本机是 Claude Code 还是 codex，并用软链方式挂载 skill 目录，git pull 后即时生效，无需重复安装，也支持只装单个 skill、只装到某个 agent 或整体卸载。运行前置条件极简：Node ≥ 18、当前会话的模型额度，出图能力可选依赖 codex CLI 内置的 $imagegen，无需任何 API key。仓库强制要求每个 skill 提供不调用模型、不消耗额度的 selftest.mjs，确保确定性逻辑在本地 1 秒内即可回归，替代 CI。
在「AI Agent Skill」这个新兴形态上给出了一个可参考的工程范式：跨 Claude Code 与 codex 双运行时、零依赖、软链安装、强制 selftest，把小说到角色设定集这种典型多模态创作流程封装成可复用产物，对做 AI 短剧、内容创作工作流的团队具有直接借鉴价值。

SkillForge ⭐ 105

面向 AI Coding Agent 的技能版 npm

RustNode.jsTypeScriptFastifyNext.js 14Tailwind CSSSQLitepnpmMCP 协议Ed25519 / minisigGitHub ActionsGitHub Pages
SkillForge 是一个面向 AI Coding Agent（Claude Code、Cursor、Codex、Gemini CLI 等）的本地优先、模型无关、MCP 原生的技能运行时。它把过去只停留在提示词片段或仓库模板层面的 Agent 技能，升级为具备结构化清单、版本管理、依赖声明、权限边界与评测基线的独立可复用单元，让 Agent 能像安装 npm 包一样安装、组合、执行技能。每个技能由 skill.yml、SKILL.md、eval.md、scripts 与 references 组成，通过 allow.read_paths / write_paths / net_hosts 白名单实现沙箱化读写与网络访问约束，并可通过 skillforge serve 命令一键暴露为 MCP 工具供客户端调用。项目采用 Rust 编写核心 CLI（core 模块负责 serve/run/validate/eval 与 Seatbelt 沙箱），配合基于 Fastify 的 registry-service 提供 /v1/skills 协议、Scope RBAC、API Token 与完整审计日志，Next.js 14 SSR 构建的 registry-web 提供技能市场、版本对比、审计日志和协议文档等界面。分发链路支持 GitHub Releases、远程多源聚合、本地 SQLite 索引三种模式，并使用 Ed25519 minisig 风格签名保证 tarball 完整性。公开仓仅存放技能源、文档与镜像配置，构建产物由私有 Core 仓 Actions 跨仓推送至 gh-pages。
当前 Agent 生态里的技能几乎都以散落的提示词或模板存在，缺少版本、权限与运行边界。SkillForge 用 npm 式的分发思路 + MCP 原生接口 + 沙箱白名单，把技能升级为可校验、可组合的基础设施，并同时给出 CLI、Registry Service、Web UI 与签名链的完整实现，是补齐 AI Coding Agent 缺失基础层的一次系统性尝试。

LongHorizon-Harness 长时程智能体框架 ⭐ 507

让 AI 智能体持续可靠完成长时程任务

Python ≥ 3.10Claude CodeCodex CLIAgentAdapter 抽象层可插拔 Environment 协议计算机使用插件（Computer-Use Plugins）
LongHorizon-Harness 是由高德（AMAP-ML）团队开源的长时程计算机使用（Computer-Use）执行框架，旨在让 AI 智能体像人类一样跨桌面应用与命令行连续工作数十小时，直至复杂任务真正完成。它不训练新模型，也不替换现有智能体，而是构建在 Claude Code、Codex CLI 等主流智能体之上，负责执行调度、状态管理与结果验证。项目的核心设计是将角色三分：Manager 维持原始目标与已验证进度并规划下一步；Executor 每轮以新鲜上下文专注执行单一明确子任务，避免上下文膨胀导致的状态漂移；Auditor 在真实环境中独立检查文件、接口、日志与测试，只有通过独立验证的结果才会写入持久任务状态，从而实现可恢复的可靠进展。它同时支持 GUI 与 CLI 混合工作流，可在浏览器、终端、办公软件、设计工具乃至 3D 软件之间无缝衔接。模型层面无绑定，Claude、GPT、Qwen 等均可通过 AgentAdapter 接入，Manager/Executor/Auditor 三个角色还能各自使用不同模型或后端，以在质量、速度和成本之间取得平衡。项目提供一键安装、doctor 诊断、统一计算机使用插件管理以及 WeaveBench、OSWorld 2.0、Terminal-Bench 2.1 等基准测试结果，覆盖前端开发、数据分析、运维调试、设计、游戏、文档、空间推理等数十种真实任务域。
在当前智能体普遍受限于单轮上下文与状态漂移的背景下，LongHorizon-Harness 提出了一条务实的工程路线：不重造模型，而是通过角色分离与独立审计把"可验证的持久状态"作为一等公民。它同时覆盖 GUI 和 CLI，并在 WeaveBench、OSWorld 2.0、Terminal-Bench 2.1 等硬核基准上给出量化收益，还登顶了 Hugging Face Daily Papers 周榜，代表了长时程 Computer-Use Agent 领域一个具备工业落地感的方向。

diri ⭐ 233

macOS 原生编码智能体并行编排器

RustGPUI (Zed)Swift 6PTY / 终端仿真tmux + SSHMCP (Model Context Protocol)Homebrew Cask
diri 是一款面向 macOS 的原生编码智能体（Coding Agent）编排工具，专为需要同时驾驭多个 AI 编程助手的开发者设计。它可以在同一界面下并行运行 Claude Code、Codex、Cursor、Gemini 以及普通 Shell 会话，并支持将这些会话分布在不同的 git worktree 或通过 ssh+tmux 部署到远程主机上。项目最大的亮点在于类 tmux 的持久化能力：由后台守护进程 dirijord 持有 PTY，即使关闭 App 或重启守护进程，会话依然存活并可回放。diri 还能通过读取智能体在终端上实际渲染的画面，判断每个会话处于「工作中 / 等待用户 / 已完成」的状态，让用户无需逐一查看终端即可掌握全局进度。此外，它内置 MCP 服务器，允许一个运行中的智能体去派生并监督另一个智能体，实现「智能体编排智能体」。在技术架构上，桌面端使用 Rust 搭配 Zed 团队开源的 GPUI 框架，负责窗口、侧边栏、终端渲染与命令面板；核心守护进程 dirijord 由 Swift 6 实现，管理 PTY、无头终端仿真、会话注册与持久化、worktree 及控制套接字。新增智能体仅需在 manifests 目录添加一份 JSON 描述文件，无需编写代码。项目采用 Apache 2.0 协议，官方通过 Homebrew Cask 分发通用二进制（Apple Silicon 与 Intel），同时 Rust 版引擎正在开发以支持 Linux 与 Windows。
在 AI 编码智能体井喷的当下，如何高效并行使用多个 Agent 成为开发者的实际痛点。diri 用原生 macOS 应用 + 后台守护进程的架构给出了「多智能体 IDE 外壳」的可行方案：既保留了终端与 PTY 的真实性，又通过屏幕读屏获得跨 Agent 的统一状态视图，并用 JSON manifest 让新增 Agent 门槛极低。Rust + Swift 双语言架构、GPUI 渲染、MCP 智能体编排以及正在推进的跨平台 Rust 引擎，都让它在同类工具中显得工程质量扎实、前瞻性强，值得关注多智能体协作方向的开发者持续跟进。
