APEX 推理芯片 ⭐ 628

FPGA 上位精确的开源 LLM 推理芯片

SystemVerilog/RTLFPGAPython/NumPy 黄金模型UVM 验证INT8 脉动阵列 (MXE)INT4+离群通道 KV 量化Qwen2.5 (0.5B/7B)Sigmantic AI Polaris 验证引擎
APEX 是一款完全开源、以验证优先为核心理念的大模型推理芯片（Tile）设计。项目在真实 RTL 中实现了一个完整的 Transformer 解码器层，涵盖注意力、KV 缓存压缩、Softmax、RMSNorm、RoPE、SwiGLU 与残差连接等模块，并已成功在 FPGA 硬件上运行真实的 Qwen2.5-0.5B 模型，实测吞吐 0.56 tok/s，相较基线实现 140 倍提升。架构上采用时分复用的 INT8 脉动阵列 MXE 承担全部 7 类矩阵运算，通过 KVQ 引擎将 KV 缓存以 INT4+离群通道形式在数据通路内即时压缩/解压，并由 TIP 重要性单元动态分配精度层级（KVQ8/KVQ4/KVQ4+outliers），使得读速度在长上下文下保持平稳。每个 RTL 模块均对齐可执行 NumPy 黄金模型，做到位精确一致，配合变异测试和反造假规则，保证证据链完整可追溯。项目定位为单 Tile 演示，架构参数按 7B 级模型（head_dim=128）预留，并附有从软件黄金流水线到 FPGA 硬件的完整复现路径。
在 AI 芯片普遍停留在 PPT 或闭源仿真的当下，APEX 提供了一个罕见的『开源 + 真实 RTL + 真实模型 + 真实 FPGA + 位精确黄金模型』的完整证据链，把研究重心从『算得快』转向『记得住』——将 KV 缓存压缩下沉到硬件数据通路并结合自适应精度调度，直击边缘 LLM 推理最痛的内存墙问题；同时其反造假的验证方法学和实测/预估严格区分的写作规范，对硬件开源社区具有示范意义。

AI 求职助手 ⭐ 816 (+816 today)

本地 CLI 驱动的开源 AI 求职工具

Claude CodeCodex CLIOpenCodeAntigravity大语言模型 (LLM)提示词工程本地文件系统
该项目是一个开源的 AI 驱动求职辅助工具，定位为运行在开发者本地 AI 编码 CLI 环境中的一站式求职工作流。它借助 Claude Code、Codex、OpenCode、Antigravity 等主流 AI 编码命令行工具作为运行时载体，将大语言模型能力嵌入到求职者的日常工作流中，避免依赖云端 SaaS，从而在保护简历、求职偏好等敏感数据隐私的同时，充分利用 AI 的语义理解与生成能力。功能层面，项目覆盖求职全流程：一是职位抓取，可扫描主流招聘门户网站，聚合职位列表；二是智能评估，采用结构化的 A-F 评分维度对每个岗位进行多维打分，并归一化为 1.0 到 5.0 的综合评分，帮助用户快速筛选高匹配度机会；三是简历定制，根据目标岗位的描述自动调整并优化 CV 内容，突出与职位要求相关的经历与技能；四是投递跟踪，记录申请状态、时间线与后续动作，形成个人求职看板。技术栈上，项目并非传统意义上的独立应用，而是构建于 AI 编码 CLI 生态之上，通过提示词工程、结构化评分规则与本地文件系统协作实现能力落地，天然兼容多种模型后端。整体设计强调本地化、可组合与可移植，适合希望以工程化方式管理求职过程的开发者。
在 AI 求职工具普遍走 SaaS 路线的当下，该项目反其道而行之，把求职流程沉入开发者已在使用的 AI 编码 CLI，兼顾隐私、可定制与工程可控性；结构化评分 + 简历定制 + 投递跟踪的组合，将模糊的‘找工作’抽象为一个可版本化、可复现的工作流，对技术人群尤具吸引力。

DSH 订阅式 LLM 插件 ⭐ 208

用订阅账号替代 API Key 接入 DSH

TypeScriptNode.jstsdownpnpmDeepSeek Harness Plugin APIOAuth 2.0 (PKCE)OpenAI/Anthropic/xAI HTTP APIs
dsh-plugin-subscriptions 是 DeepSeek Harness (DSH) 的第三方插件，让用户直接把已有的 ChatGPT (Codex)、Claude Pro/Max 与 Grok (X Premium) 订阅接入 DSH，作为 LLM Provider 使用，无需任何 API Key。Codex 与 Grok 在 Web UI 的 Settings → Subscriptions 中通过 OAuth 登录，Claude 则从本地 Claude Code 会话（macOS Keychain 或 ~/.claude/.credentials.json）导入凭证；所有 Token 以 0600 权限保存于 ~/.dsh/plugins/subscriptions/auth.json 并自动刷新。登录后，各家的实时模型目录会加入会话模型选择器：Codex 从 chatgpt.com/backend-api/codex/models 拉取，Grok 从 api.x.ai/v1/models 拉取，Claude 使用静态目录。支持模型的 Reasoning Effort 选择、Codex Fast 优先级切换（priority tier，附 /fast 斜杠命令）、视觉输入模态自动转换，以及订阅用量面板（5 小时窗口、周窗口、按模型周窗口，含进度条与重置时间）。插件同时注册三个工具：x_search（Grok 的 X 站内搜索）、image_generate（gpt-image-2 或 grok-imagine-image-2.0，结果内联渲染并本地落盘）、video_generate（grok-imagine-video-1.5，异步提交轮询，MP4 内联播放）。通过 dsh plugin add 从 npm 或 GitHub 安装，可用 overlay.yml 覆盖模型目录与 stream 超时等参数。
它把消费者级的 ChatGPT Plus/Pro、Claude Pro/Max、X Premium 订阅统一封装成 DSH 的标准 Provider，为个人开发者提供了绕开按量计费 API 的实用路径，同时保留了官方 CLI 的高级能力（Codex fast tier、Grok 图像/视频生成、X 搜索），并把订阅用量、Reasoning Effort、模型目录都以工程化方式接入 UI，是订阅账号复用与多模态工具集成的一个高完成度参考实现。
