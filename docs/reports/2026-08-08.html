Agent 视觉工具箱 ⭐ 348

让纯文本 LLM 智能体拥有视觉能力

Shell CLI本地透明代理（Local Proxy）Agent Skills 标准多模态视觉 API（VLM）Codex / Claude Code / OpenCode 等 Agent 扩展
agent-vision-toolkit 是一个为纯文本大模型（如 DeepSeek）设计的视觉能力增强工具箱与技能包，让原本不具备多模态能力的 Coding Agent 也能完成看图、识图、还原 UI、GUI 自动化等视觉任务。项目提供两类组件：其一是一组视觉工具 CLI（如 glance 用于图片问答、ground 用于元素定位等），配合一个名为 vision-tools 的 Skill，指导 Agent 何时调用哪个工具、按何种顺序执行、如何验证结果；其二是可选的无缝集成层，通过本地透明代理与单文件原生插件，让用户直接粘贴图片以及 Agent 内置的图片工具都能自然工作，无需额外提示。核心典型场景包括长截图与聊天记录 OCR、根据草图或设计稿还原前端 UI、图标/Logo/SVG 还原、白板草图转 Mermaid 结构化代码，以及基于截图的 GUI 操作闭环（定位—操作—再截图—校验）。项目已在 Codex + DeepSeek 上完整验证，并端到端跑通 Claude Code、Pi、Oh My Pi、OpenCode 等主流 Agent，主张视觉能力不必内置于模型，而可存在于 Harness（外壳）中，让文本模型 Agent 借助工具反超原生多模态模型。
它把「让文本模型看图」这件事系统化了：不只是加一个 image-to-text 工具，而是提供了一整套围绕视觉任务的方法论（何时看、看什么、如何验证），并通过本地代理让粘贴图与原生图片工具透明工作，几乎零改造接入主流 Agent。对于大量使用 DeepSeek 等纯文本模型跑 Agent 的开发者，这是一种以外部工具链绕过模型模态限制、性价比极高的补强思路。

shuohao-skills ⭐ 188

AI 编码 agent 的通用 skill 集合

Node.js (≥18, 标准库)Bash 安装脚本Claude Code CLIcodex CLIGitHub Actions (预留未启用)
shuohao-skills 是一个面向 AI 编码 agent 的 skill 集合仓库，同时兼容 Claude Code 和 codex 两种 CLI 环境。项目采用「一个 skill 一个目录、自包含可单独拷走」的组织约定，目前收录的首个 skill 是 novel-characters，它能把一篇完整小说拆解成角色设定集，产出物包括人物画像、卡通形象提示词、音色提示词以及三视图，方便后续接入图像与语音生成流程。安装环节由 scripts/install.sh 处理，脚本会自动检测本机装的是 Claude Code 还是 codex，并把 skills 目录以软链方式挂到 ~/.claude/skills 或 ~/.codex/skills，好处是 git pull 之后新版本立即生效，无需重装；同时脚本支持指定单个 skill、限定目标 CLI 以及一键卸载软链。运行前置只有两条硬要求：Node ≥ 18（脚本仅使用标准库，零 npm 依赖）和当前会话自带的模型额度，无需任何 API key；codex CLI 属于可选项，仅在需要通过内置 $imagegen 出图时才用到。仓库约定每个 skill 必须包含 SKILL.md 工作流说明和 scripts/selftest.mjs 自测脚本，且自测不得调用模型、不得消耗额度，只覆盖确定性逻辑，这为多 skill 扩展提供了统一的质量基线。项目预留了跨平台跨 Node 版本的 GitHub Actions workflow（Ubuntu/macOS × Node 18/22/24），但尚未启用，作者在 README 中坦率说明当前仅在 macOS + Node 24 验证过，并给出启用步骤。
在 Claude Skills 生态刚起步的阶段，这个仓库给出了一个可复制的工程化范式：跨 agent 复用、软链热更新、零依赖自测、按 skill 目录自包含。相比只面向单一平台的 prompt 合集，它把 skill 当作可维护的软件工件来对待，且首个示例 novel-characters 直击小说到多模态素材的实际痛点，对做 AI 内容创作管线的开发者有直接借鉴价值。

SkillForge ⭐ 105

AI Agent 技能版 npm 运行时

SkillForge 是一个面向 AI Coding Agent（Claude Code、Cursor、Codex、Gemini CLI 等）的本地优先、模型无关、MCP 原生的技能运行时。它把 Agent 能力封装成可校验、可组合、可分发的独立单元，让 Agent 像装 npm 包一样复用技能，同时通过白名单沙箱约束读写与网络边界。当前处于 Phase 1 MVP 阶段，已经形成完整的本地加远端闭环：Rust 编写的 core CLI 提供 run/serve/validate 三大命令，实现 skill.yml 严格校验、Plan-Act-Observe-Reflect 循环、Token 预算截断、Ollama 与 OpenAI 兼容模型接入，并在 macOS 上自动接入 Seatbelt 平台沙箱；TypeScript 编写的 registry CLI 支持多源聚合、@scope 路由、Bearer Token 鉴权、Ed25519 minisig 签名发布与安装校验，以及 GitHub Release 分发同步；registry-service 基于 Fastify 加 SQLite 对齐 /v1/skills 协议，具备 publish/yank RBAC 与完整审计日志；registry-web 用 Next.js 14 与 Tailwind 呈现首页、技能列表、版本对比、审计日志与协议文档。内置 fix-ci、grep-ts、doc-gen 三个示例技能，通过 MCP 的 tools/list 与 tools/call 直接暴露给 Agent 客户端，形成从技能编写、校验、评测到分发消费的一体化基础设施。
大多数 Agent 技能方案还停留在提示词片段或仓库模板层面，SkillForge 把它工程化为一个带清单、签名、RBAC、审计和沙箱的分发平台，接近 npm 之于前端的角色定位。跨 Rust 与 TypeScript 双栈交付、原生对齐 MCP 协议、并已跑通本地加远端加 Web UI 完整链路，对想构建自有 Agent 能力体系或研究 AI 工具供应链的团队都有参考价值。

LongHorizon-Harness ⭐ 388

长时程电脑操作智能体执行框架

Python ≥ 3.10Claude CodeCodex CLIOpenClawAgentAdapter 插件协议Environment 可插拔执行环境协议
LongHorizon-Harness 是由高德（AMAP-ML）团队开源的长时程（Long-Horizon）计算机操作智能体执行框架，定位为运行在 Claude Code、Codex CLI 等现有 Agent 之上的执行、状态管理与结果验证系统。它并不训练新模型，也不替代现有 Agent，而是通过独立的角色分工，让智能体在真实桌面与命令行环境中自主工作数十小时，跨应用推进复杂任务而不发生状态漂移。核心设计采用三角色架构：Manager 维护原始目标与已验证进度并规划下一步，Executor 每轮以全新上下文聚焦单一任务，Auditor 独立检查文件、接口、日志与测试，只有通过独立验证的结果才会进入持久化任务状态，从而实现新鲜上下文执行、可恢复进度和可审计的可靠推进。框架同时覆盖 GUI 与 CLI 场景，可在浏览器、电子表格、设计软件、3D 工具与终端命令间无缝流转，并通过轻量级 AgentAdapter 接入 Claude、GPT、Qwen 等任意模型，三个角色可分别选用不同后端以平衡质量、速度与成本。项目提供 doctor 诊断、统一的计算机操作插件管理、只读审计校验和进程清理等工程能力，并在 WeaveBench、OSWorld 2.0、Terminal-Bench 2.1 等基准的数百个真实任务上完成评测，覆盖前端开发、数据分析、运维调试、设计处理、游戏交互、文档演示、空间推理、桌面操作、科研教育与创意生产等十余个领域。
长时程 Agent 是当前工程化落地的最大瓶颈，绝大多数框架仍停留在单轮或短链任务的演示。LongHorizon-Harness 不训练模型、不改造 Agent，而是从执行层用三角色隔离＋独立验证＋持久化状态的思路解决上下文漂移这一根本问题，并在数百个真实 GUI/CLI 混合任务上给出可量化的收益，登上 Hugging Face Daily Papers 周榜第一。它把 Claude Code、Codex 这类通用 Agent 变成能连续工作数十小时的可靠执行体，对做 Agent 平台、RPA 升级或研究长时程规划的团队都具备直接参考与集成价值。
