Agent 视觉工具箱 ⭐ 332

让纯文本 LLM 拥有视觉能力

Shell / Bash CLIPython本地 HTTP 代理Agent Skills 规范视觉大模型 API（VISION_API_KEY/BASE_URL/MODEL）Mermaid / Graphviz / HTML / CSS / SVG
agent-vision-toolkit 是一个专为纯文本模型（如 DeepSeek）设计的视觉能力扩展工具包，目标是让不具备原生多模态能力的编码 Agent 也能像多模态 Agent 一样自然地处理图像任务，甚至在配合方法论后表现更优。项目提供两大类组件：一是一组视觉工具 CLI（如 glance 用于多轮图片问答、ground 用于屏幕元素定位等）及配套的 vision-tools 技能包，任何能调用 Shell 的 Agent 都可直接使用；二是可选的无缝集成层，通过本地透明代理和单文件原生插件，让用户直接粘贴的图片以及 Agent 内置的图像工具都能自动走该工具链，无需额外提示或安装。核心典型场景包括长截图 OCR、聊天记录提取、UI 截图/草图还原为 HTML/CSS、图标 Logo 还原为透明 PNG 或 SVG、示意图转 Mermaid/Graphviz 结构化代码、以及基于截图的 GUI 自动化操作。技能包不仅告诉 Agent 用哪个工具，还给出何时使用、调用顺序、以及如何验证结果的完整方法论。项目已在 Codex + DeepSeek 的真实会话中验证，并端到端适配了 Claude Code、Pi、Oh My Pi、OpenCode 等主流 Agent 环境。
在多模态模型价格与延迟仍是瓶颈的当下，该项目用工具化 + 技能方法论的方式，把便宜、快速的纯文本模型武装成可以看图、还原 UI、操作 GUI 的完整 Agent，并且已在 Codex、Claude Code、OpenCode 等多个主流环境跑通端到端流程。它不仅是几个 CLI 的堆叠，更提供了一套包含工具选择、调用顺序、结果验证的可复用视觉任务 SOP，对希望降低多模态成本或想扩展现有 Agent 视觉能力的开发者极具参考价值。

LongHorizon-Harness 长程智能体框架 ⭐ 335

让 AI 智能体持续可靠完成复杂长程任务

Python ≥ 3.10Claude CodeCodex CLIOpenClawAgentAdapter 插件协议Environment 可插拔执行环境WeaveBench / OSWorld 2.0 / Terminal-Bench 2.1
LongHorizon-Harness 是由高德地图（AMAP-ML）团队开源的长程计算机使用（computer-use）执行框架，专注于让 AI 智能体像人类一样操作整台电脑，跨桌面应用与命令行环境连续工作数十小时，且不发生状态漂移。它并不训练新模型，也不替换现有智能体，而是作为一层执行、状态管理与结果校验系统，运行在 Claude Code、Codex CLI 等主流 Agent 后端之上。核心设计将任务拆分为三种角色：Manager 负责维护原始目标与已验证进度、Executor 每轮以全新上下文聚焦单一子任务、Auditor 独立检查文件、接口、日志与测试。只有通过独立校验的成果才会写入持久任务状态，即使上下文刷新或某一步失败，系统也能基于已验证进度继续推进。框架同时支持 GUI 与 CLI 工作流，可让一个任务在浏览器、命令行、桌面软件和终端之间无缝衔接。通过轻量级 AgentAdapter，用户可为三个角色分别配置不同的模型或后端，以在质量、速度与成本之间权衡。项目提供一键安装、doctor 诊断、统一 computer-use 插件管理，并在 WeaveBench、OSWorld 2.0、Terminal-Bench 2.1 等基准的数百个真实任务上验证了效果，覆盖前端开发、数据分析、运维排障、设计制图、3D 空间推理、文档演示、游戏交互与工程计算等领域。
长程智能体是当前 AI Agent 领域最难啃的骨头：单模型再强，也扛不住数十小时任务中的上下文遗忘、状态漂移和错误累积。LongHorizon-Harness 用工程化的方式给出了一个可复用的解法——把规划、执行、审计三种职责彻底解耦，并以独立验证作为进入持久状态的唯一门槛。它不与现有 Claude Code / Codex 生态竞争，而是构成其上层协调层，具备很强的落地实用性。项目已在数百个真实任务上验证效果，登上 Hugging Face Daily Papers 周榜第一，值得关注长程 Agent、Computer-use 与自主工作流的开发者深入研究。

Impeccable Lite 是从 Impeccable 项目中提炼出的独立轻量版本，专注为 AI 编码代理提供前端设计判断力，避免生成千篇一律或粗糙的界面。它剥离了原项目中的插件机制、命令行工具、生命周期钩子、浏览器实时编辑、确定性检测器和安装器等复杂生态，仅保留核心的设计指导层，最终以一份 SKILL.md 文件呈现。该 Skill 涵盖营销页、产品 UI、编辑排版和作品展示等多种设计模式，提供关于排版、色彩、布局、交互、动效的实用指引，并强调无障碍访问、响应式行为、性能优化和边缘场景处理。安装方式极简：在目标平台的 skills 目录下新建 impeccable-lite 文件夹并放入 SKILL.md 即可。项目兼容 Claude Code、Codex、Cursor、Gemini CLI、GitHub Copilot、Kiro、OpenCode、Qoder、Grok Build 等十余种主流 AI 编码代理平台，对不支持 Agent Skills 的工具，也可将内容直接复制到项目指令作为兜底方案。项目基于 Apache 2.0 协议开源。

flornkm/skills 是一个面向 AI 编码智能体（Agent）的技能（Skills）集合库，旨在为大语言模型补充其训练数据中缺失或罕见的设计与工程概念。项目遵循两条严格的收录标准：其一，只教授 LLM 未被训练过的新兴或冷门概念；其二，只沉淀经过多个代码库验证的、有明确主张的工作流。用户可以通过 `npx skills@latest add flornkm/skills` 一条命令快速将这些技能注入到自己的智能体工作环境中，避免市面上大量低质量技能包带来的噪声。当前库中收录的代表性技能是 prefer-container-queries，它引导智能体使用 Tailwind 的容器查询替代传统的视口断点，使组件能够根据自身所在容器的空间尺寸做出响应式布局。整体项目结构轻量，每个技能以独立目录下的 SKILL.md 文件形式组织，便于按需引用与扩展。
