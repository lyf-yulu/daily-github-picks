Antibes Holiday 是一款便携式视觉创作技能包，同时以 Agent Skill 和 Codex Plugin 两种形态发布，用于生成松弛感的原创黑笔插画、叙事场景、表现性笔触以及早期 Logo 探索。项目并不绑定特定艺术家身份，而是抽象出一套通用的视觉语法，涵盖物理笔触行为、速记式识别、克制的不完整感、因果式画面调度、主动留白与非平衡比例等要素。仓库通过 SKILL.md 定义执行流程，并以 style-system.md 与 prompt-recipes.md 作为组合式补充参考，配合笔触校准图与七张示例输出。它在具备图像生成能力的 Codex 环境下可完成完整绘制与编辑；在仅有栅格图像工具的 Agent 上会调用原生渲染器；无渲染能力时则优雅降级为可直接使用的提示词与校验清单，避免虚假声称完成绘图。安装方式支持 gh skill、npx skills 与 codex plugin marketplace 三种路径，采用 MIT 许可证。

Trajex ⭐ 50

AI 编码会话统一索引与浏览工具

TypeScriptNode.js 22ElectronSQLite (node:sqlite / better-sqlite3)FTS5 全文检索chokidar 文件监听electron-vite
Trajex 是一个将 Claude Code、Codex、Kimi Code 与 Pi 等多种 AI 编码 Agent 产生的 JSONL 会话记录统一索引至同一个本地 SQLite 数据库的工具，衍生自 tommy0103/obelisk。它包含两个共享同一份索引的组件：面向 Agent 的 trajex CLI 支持毫秒级 JS 脚本查询与 FTS5 全文检索；面向人类的 Electron 桌面 App 提供 Sessions 浏览、Memory 管理、Activity 热力图与周月 Recap 卡片等直观界面。索引器会监听各 provider 的默认目录进行增量重建，支持根会话、子 Agent、workflow、tool calls、diffs 等多层数据的捕获。通过配套的 /trajex Skill，编码 Agent 能够自主编写查询脚本、以自然语言回答历史问题，并将有价值的结论沉淀为 markdown memory 供后续会话复用，实现会话历史的可检索与可复盘。
在 AI 编码 Agent 生态碎片化的当下，Trajex 通过一套统一的本地索引让分散的会话历史真正可查询、可复用，兼顾 Agent 自动化查询与人类可视化浏览两种使用场景。

南鸢写真提示词 Skill ⭐ 121

面向人像写真的中文提示词 Agent Skill

Agent Skill 规范Markdown（SKILL.md 规则）npx / Node.js CLIPrompt Engineering
南鸢写真提示词是一个面向 Agent 生态的 Skill 插件，专注于中文人像与写真摄影场景的提示词生成。项目定位清晰：不直接调用图像模型生图，而是作为 Agent 的能力扩展，输出高质量、可复用的中文写真提示词，交由下游图像模型完成成片。核心能力覆盖四种典型工作流：完整中文提示词撰写、系列母版设计、同系列变体扩展，以及网页端抽卡关键词与参考图拆解，能够帮助用户在保持统一风格的前提下衍生出构图、动作、服装均不重复的系列作品。在专业性上，Skill 明确区分了固定成像机制、单张现场光线与皮肤区域反射三层参数，从而避免直闪近景常见的全脸油膜问题，体现出对摄影布光和皮肤质感的细致理解。安装与更新通过 npx skills 命令行完成，支持全局安装以及在 Agent 内以自然语言触发更新，但不支持热更新，需要重新加载任务。完整规则约束记录在 SKILL.md 中，采用 MIT 协议开源。整体项目体现了 Agent Skill 生态下垂直领域知识的封装范式：以提示词工程为核心，以规范化文档为载体，将摄影领域的经验沉淀为可分发、可组合的能力单元。
在 AI 写真赛道中，多数项目直接绑定特定图像模型，而本项目将提示词能力从生图流程中解耦，作为可复用的 Agent Skill 分发，体现了垂直领域知识资产化的思路。摄影层面对布光与皮肤反射的分层建模，也超出了通用提示词模板的粒度，对同类中文写真提示词工程具有参考价值。

pi-config 是作者 realchendahuang 分享的一份可直接复刻的 Pi Coding Agent 配置，把日常筛选出来的 17 个插件、18 个全局 Skill 和 2 个 MCP Server 打包整理，并配一键安装脚本 install.sh，目标是把 Pi（开源终端 AI 编码代理，npm 包 @earendil-works/pi-coding-agent）改造成一个能多代理协作、能省 token、能驱动浏览器的全能编码助手。README 兼具教程属性，先系统性讲解 Pi 的分层架构：TUI/RPC 交互层、Agent Loop 代理循环、Providers/Models 多模型抽象、Tools 工具层、Extensions TypeScript 扩展、Skills/Prompts 过程知识、Themes 主题以及 Packages 分发单位，并说明 npm、git、本地路径三种包来源和各配置文件位置。然后按轻中重三档介绍改造方式：写 Skill（纯 Markdown）、接 MCP Server（跨 agent 工具协议）、写 Extension（订阅生命周期事件、注册工具/命令/主题）。插件按用途分组，覆盖代理编排（pi-subagents 支持 single/chain/parallel/async/forked-context 五种模式、pi-goal、pi-plan-mode）、代码智能（pi-lens 提供 ast-grep 结构化搜索、tree-sitter 规则、LSP 诊断）等场景，非常适合想深入定制终端 AI 代理的开发者参考。
