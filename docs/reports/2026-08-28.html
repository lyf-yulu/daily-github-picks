swissdevjobs-cli 终端求职工具 ⭐ 81

终端搜索透明薪资技术岗位

Python 3.9+Python stdlib（无第三方依赖）SQLiteMCP (Model Context Protocol)Claude Code Pluginuv / uvxMongoDB ObjectId 解析
swissdevjobs-cli 是一个零依赖的 Python 命令行工具，聚合了 8 个国家（瑞士、德国、英国、美国、加拿大、荷兰、法国、新加坡）共 9 个招聘板块的技术岗位数据，涵盖约 4700 个强制公开薪资范围的技术职位，以及瑞士 jobs.ch/jobup.ch 的约 5 万个全行业职位和新加坡 MyCareersFuture 的约 9000 个 IT 职位。核心亮点是把薪资作为一等公民过滤条件（--min-salary），通过解析 MongoDB ObjectId 还原真实发布时间以识别被平台重新置顶的旧职位，并用本地 SQLite 记录已投递岗位实现跨板块去重。工具面向 AI Agent 场景设计，所有命令支持 --json 输出，附带 MCP Server 和 Claude Code 插件，可通过 uvx 一键接入 Claude Code，用自然语言驱动搜索与投递流程。仅使用 Python 标准库，不引入任何第三方依赖，避免供应链风险。
在 AI Agent 求职自动化场景下罕见地做到零依赖、跨国多板块聚合、且原生支持 MCP，把薪资透明度与 LLM 工具调用结合，是 Agent-native CLI 设计的优秀范例。

store-screenshots 是一款面向 Claude Code 与 OpenAI Codex 的 AI Agent Skill，能够将开发者原始的 App 截图自动转换为可直接上架 App Store 与 Google Play 的营销素材。它使用纯 CSS 绘制 iPhone、iPad、Galaxy、Fold、Flip 等设备外框，无需下载第三方模型或担心授权问题；同时会从应用的 colors.xml、.xcassets 与应用图标中提取真实品牌色，生成 Modern、Minimal、Pop、Dark 等风格背景，并基于每屏内容撰写以用户价值为导向的营销文案，在用户确认后再全量渲染。若开发者尚未准备截图，Agent 还可通过 adb、simctl deep link、idb、Maestro 等自动驱动应用完成截屏，并将状态栏统一为 9:41 与满电。最终输出严格符合 1320×2868、1284×2778、2064×2752、1080×1920 等商店规范的 PNG，并通过 sips 或 ImageMagick 逐像素校验，全流程本地运行，无上传、无水印。

跨会话持久化上下文引擎 ⭐ 143 (+143 today)

为AI代理提供跨会话记忆能力

AI/LLM上下文压缩多代理集成会话中间件
该项目是一款面向多种AI编程代理的持久化上下文管理工具，旨在解决AI代理会话结束后上下文丢失的问题。它能够在会话进行期间全程捕获代理的操作行为，利用AI技术对海量上下文数据进行智能压缩，并在后续新会话启动时自动注入相关的历史上下文，从而实现跨会话的记忆延续能力。项目具有广泛的兼容性，支持包括 Claude Code、OpenClaw、Codex、Gemini、Hermes、GitHub Copilot、OpenCode 等在内的主流AI编程助手与代理框架，可作为通用中间层无缝接入各类工作流。通过这种捕获-压缩-注入的三阶段机制，开发者可以让AI代理真正拥有长期记忆，避免每次会话都需要重新解释项目背景与历史决策，显著提升复杂项目中人机协作的连续性与效率。

agenttrail ⭐ 282

本地AI编码智能体实时观测地图

Node.js (≥20)原生 HTML/CSS/JS 前端Server-Sent Events (SSE)文件系统 WatcherClaude Code Hooks (.claude/settings.local.json)Markdown 约定 (PLAN.md / CLAUDE.md / AGENTS.md)npm/npx 分发
agenttrail 是一个面向 AI 编码智能体（Claude Code、OpenAI Codex、Cursor 等）的本地开源可观测性工具。它将智能体的计划、工具调用、文件变更与任务进度实时可视化为一张项目地图，帮助开发者随时了解智能体是在推进、卡住，还是悄悄修改了已声明完成的部分。项目通过 `npx agenttrail` 一条命令即可启动，无需账号、无需全局安装、无遥测数据，仅绑定 127.0.0.1，保证纯本地运行。核心机制依赖两大信号：`Declared`（智能体声明正在做的组件与任务）和 `Observed`（文件系统实际发生的写入变化），当两者不一致时便能定位问题。执行 `npx agenttrail init` 后，agenttrail 会向 `CLAUDE.md`/`AGENTS.md` 注入约定、生成 `PLAN.md` 骨架，并安装 Claude Code 本地钩子，让智能体自行维护一份 5-9 个组件的仓库地图，包含依赖箭头、进度、完成/进行中/阻塞状态。界面呈现 VS Code 风格文件树、运行卡片、会话计划、任务清单与流式工具调用行。技术上仅由约 470 行无依赖的 Node.js 单文件守护进程与一个静态 HTML 页面组成，通过 SSE 推送事件，无数据库、无构建步骤，已在 7.8 万文件的大型仓库上验证可用。
在 LLM 可观测性普遍聚焦于 token、延迟、trace 的当下，agenttrail 独辟蹊径地关注「编码智能体在仓库里到底做了什么」，把 Agent 工作过程从事后 transcript 回放变成实时项目地图。它以极小的技术复杂度（单文件守护进程 + 静态页面）和严格的本地化设计（无云、无账号、只读观察）解决了长时间运行 Agent「是否在推进、是否偷偷回改」的真实痛点，同时通过 PLAN.md 约定让智能体自我维护项目结构，是 Agent 时代开发者工具形态的一次有意思的探索。
