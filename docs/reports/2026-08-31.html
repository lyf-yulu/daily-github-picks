Forward Implementation First ⭐ 126

让编码代理少做记账、先出成果

MarkdownYAML frontmatterShell (install.sh)Agent Skills 规范Claude CodeCodex
Forward Implementation First 是一个面向编码代理（Coding Agent）的通用技能（Agent Skill），旨在解决长周期代理流水线中普遍存在的一种失败模式：代理沉迷于服务自己发明的行政记账工作——诸如内容哈希、锁文件、执行回执、认证标记、进度元数据等，却停止交付真正的产品。该技能仅约 150 行 Markdown，模型无关、工具无关、领域无关，可用于 Claude Code、Codex 等主流代理。其核心机制是要求代理在每次动作前进行三分类：语义实现、聚焦验证、行政记账；前两类照做，第三类除非用户明确要求或属于产品本身，否则一律跳过，甚至在其无谓阻塞流程时直接删除依赖。项目同时确立了「前向游标规则」——只有输入语义变更、目标修订变更、输出损坏、运行时反证或依赖锥要求这些真实原因才允许回滚重放，缺失或过期的元数据不构成理由。此外技能还覆盖并行工作池纪律：重进程串行、廉价任务并行、根 lane 独占发布与游标推进，避免并行 worker 成为第二真相源。技能通过 install.sh 一键安装到 Claude Code、Codex 或 .agents 共享目录，遵循 Agent Skills 规范，特别适合分阶段流水线、ETL、大规模代码迁移、构建发布、批处理等长时任务场景。
它把资深工程师才有的直觉——识别「假装在工作的记账行为」——压缩成一份 150 行、跨模型跨工具通用的规则文件，直击当下长时代理最烧钱也最难自查的失败模式，且以「删除阻塞性行政依赖」这种反直觉但正确的做法作为默认策略，是提示工程从「让模型更快」走向「让模型更清醒」的一次范式尝试。

swissdevjobs-cli 命令行求职工具 ⭐ 93

终端聚合搜索薪资透明技术岗位

Python 3.9+Python 标准库（零依赖）SQLiteMCP (Model Context Protocol)Claude Code Pluginuv / pipx / uvx
swissdevjobs-cli 是一个零依赖的 Python 命令行工具，聚合了 8 个国家共 9 个招聘平台，让开发者在终端或 AI Agent 中搜索、筛选并投递技术岗位。核心覆盖 devitjobs 家族的 6 个强制披露薪资的 IT 招聘站（瑞士、德国、英国、美加、荷兰、法国，约 4700 个岗位），并扩展到瑞士 jobs.ch / jobup.ch（约 5 万条全行业岗位）和新加坡政府 MyCareersFuture（约 9000 条 IT 岗位）。工具将薪资作为一等筛选条件，通过解析 MongoDB ObjectId 还原岗位真实发布时间，避免招聘方刷新造成的『假新岗』；使用本地 SQLite 记录已投递记录，跨平台自动去重。项目内置 MCP Server 和 Claude Code 插件，所有命令支持 --json 输出，便于 LLM Agent 直接驱动。仅依赖 Python 标准库，可通过 uv/pipx/uvx 安装为 sdj 或 swissdevjobs 命令。
少见的将『薪资透明』作为产品核心、并以 Agent-native 方式设计的求职 CLI，零依赖 + MCP Server 组合让 LLM 可直接接管完整求职流程。

TypeScriptJavaScriptWebAssemblyTree-sitterReact图数据库/图可视化库LLM APIGraph RAG
GitNexus 是一款零服务器、纯客户端的代码智能分析引擎，所有计算均在用户浏览器中完成，无需后端支持，从而保障源码隐私与部署便利性。用户只需拖入来自 GitHub、GitLab、Azure DevOps 的远程仓库、本地代码目录或 ZIP 压缩包，即可自动解析代码结构并生成可交互的知识图谱，直观呈现文件、类、函数及其调用与依赖关系。项目内置 Graph RAG（基于图的检索增强生成）智能体，能够结合知识图谱的结构化上下文回答代码相关问题，帮助开发者快速理解陌生代码库、追溯调用链、定位关键模块。GitNexus 适用于代码探索、架构梳理、新人上手、代码评审与技术债务分析等场景。得益于浏览器端 WebAssembly 与现代前端技术，它兼具本地化的数据安全性与丰富的可视化交互体验，是一款面向工程师的轻量级代码理解工具。

sepia ⭐ 911

跨平台去AI味写作Agent技能包

Agent Skills 规范Markdown (SKILL.md)Claude Code PluginCodex PluginGrok Build PluginAntigravity plugin.jsonSkills CLI (npx skills)
sepia 是一个面向 Claude Code、Codex、Grok Build 与 Antigravity 四大 AI 编程/写作代理的可移植 Agent Skill 插件，专注于消除 AI 生成文本的痕迹（De-AI writing）。它基于 StoryScope（arXiv:2604.03136）等 12 项学术研究，指出 AI 文本真正的破绽并非词汇与句法，而在于叙事结构层面——主题被叙述者直接解释、单线因果过于工整、情感只以身体反应呈现、缺少真实世界指涉、线性时间、以主角成长收尾等。项目将这些可测量的结构性缺陷转化为三阶段修订协议：叙事架构、话语流、表层风格，并配套 30 项特征诊断表与针对 Claude、GPT、Gemini、DeepSeek、Kimi 的模型指纹修正规则。对专业文体（发布说明、PR 回复、事后复盘、工单、技术文章），项目提供按场合匹配的写作规则。工具向用户暴露四个操作入口：write（创作）、review（仅诊断）、refactor（最小改动）、recreate（重写），并保留 /sepia 通用路由。核心设计原则是「向人类分布校准，而非反转 AI 分布」，每篇文本仅选用 3–5 条修订动作以避免形成新指纹。项目采用单一规范的 SKILL.md、无平台分叉，通过各平台原生插件安装器分发，支持用户级与项目级作用域。
在满屏「AI 人味化」工具都在改词换句时，sepia 引用 StoryScope 的实验结论——仅凭叙事结构特征就能以 93.2% 的 F1 识别 AI 小说，而表层改写几乎无效——直击真正的检测面，切入点新颖且有据可查。加上一次编写、四端通用的 Agent Skill 打包方式，以及区分虚构与专业文体的分层规则设计，使其在 AI 写作工具生态中具备研究深度与工程完成度双重稀缺性。

useAgent ⭐ 129

开源 AI 员工协作平台

BunTypeScriptPostgres 16pgvectorDaytona / CubeSandboxnoVNCSlack APIGitHub AppTerraformDocker
useAgent 是一款开源的 AI 协作员平台（当前处于 Alpha 阶段），把 Claude Code、Codex、OpenCode 等主流 AI 编码代理封装成拥有独立云端计算机的团队同事：它们能使用你的工具与业务上下文完成任务，并交付网站、幻灯片、电子表格、研究报告、可测试的 PR 等成品，而不仅仅是回答问题。系统的核心设计是把每次运行建模为 Postgres 中的事件溯源时间线，运行可在后端重启后自动恢复、可完整回放并事后审阅。每个会话线程都运行在隔离的 Linux 沙箱中（支持 Daytona 托管服务或自托管的 CubeSandbox），并配备终端、代码仓库、浏览器和带 MP4 录制的 noVNC 可视化桌面。所有集成（GitHub、Gmail、Linear、Notion、HubSpot、知识库、团队记忆、技能等）均通过受信任网关以类型化工具形式提供，凭据始终留在控制平面，绝不进入沙箱。平台内建人机协同审批（Web 或 Slack 卡片）、从 GitHub 导入 SKILL.md 的版本化技能库、组织级知识检索、Slack 原生的提及即运行，以及 DOCX/XLSX/PPTX/PDF 原生产物编辑。技术栈以 Bun 为运行时，前后端分离，Postgres 16 + pgvector 存储事件与向量，Terraform 提供 Hetzner 一键部署参考，支持 AWS、GCP、Azure 及裸金属自托管，采用 AGPL-3.0 协议并提供商业许可。
在当前 AI Coding Agent 生态高度碎片化的背景下，useAgent 用一套事件契约统一了 Claude Code、Codex、OpenCode 等主流代理，把它们从『聊天助手』升级为拥有云端工作站、能交付真实产物的团队成员。它同时解决了企业落地 AI Agent 的三大痛点——凭据安全（网关隔离）、运行可靠（事件溯源+崩溃恢复）、人机审批（HITL），并支持完全自托管与数据本地化，是少数具备生产级架构思路的开源 Agent 平台。
