Antibes Holiday 是一个便携式的手绘风格插画生成工具，同时以 Agent Skill 和 Codex 插件两种形态提供。项目定位于为 AI 助手（如 Claude Agent Skills 与 OpenAI Codex 生态）注入一种统一的视觉风格能力，具体表现为 '放松的黑色钢笔线条插画'——线条随性、构图轻盈，适合博客配图、笔记装饰、社交分享与产品氛围图。作为可移植的 Skill 模块，它可以被主流 AI Agent 框架直接加载，通过约定的 Skill 描述文件与提示词模板，将风格约束、构图指南和输出规范注入到多模态模型的绘图流程中；同时作为 Codex 插件，可在代码或内容生成场景中被调用，实现风格一致的插画产出。项目强调轻量、易嵌入、跨平台复用，无需额外训练即可获得稳定的风格化视觉输出。

AgentAcct 编程智能体审计面板 ⭐ 538

追踪编程 Agent 的耗时、Token 与操作明细

待确认（README 未披露）
AgentAcct 是一个面向编程类 AI 智能体的本地优先审计与可视化面板，目标是让开发者清晰看到自己的 Coding Agent 究竟做了什么、花了多少代价。它把每一次任务拆解成一系列可追溯的工作步骤（work steps），逐步记录调用了哪些工具、修改了哪些文件、跑了哪些测试，以及消耗的时间和 Token 数量，从而把原本模糊的 Agent 行为量化成可对比、可复盘的数据。项目定位覆盖当前主流的编程 Agent 生态，兼容 Claude Code、Codex、OpenCode 等多种客户端，通过统一的仪表盘让用户在一个视图中横向比较不同 Agent 的效率、成本和风格差异。与常见的云端 Agent 观测平台不同，AgentAcct 强调 Local-first 部署理念：数据留在本机，无需注册登录，也不做任何遥测上报，天然规避源码泄露和使用行为外泄的风险，非常适合企业内部或对隐私敏感的个人开发者。凭借对任务、工具调用、文件变更、测试执行和 Token 计费的细粒度记录，它可作为 Agent 使用成本分析、Prompt 与工作流调优、以及团队内部 Agent 效果评估的基础设施。由于当前 README 内容较为精简，具体技术栈尚未公开披露，需结合仓库源码进一步确认。
在 Coding Agent 快速普及但成本与行为普遍黑盒的当下，AgentAcct 提供了一个稀缺的本地化可观测层：它不仅回答『Agent 做了什么』，还量化『花了多少 Token 和时间』，为 Agent 效果评估、成本控制和工作流优化提供数据基础。跨 Agent 的统一视图和零遥测的隐私姿态，使其在企业和独立开发者场景都具备较高实用价值。

Pi 编码代理一键安装配置方案

pi-config 是一个针对 Pi 编码代理（Pi coding agent）的完整配置方案，旨在为开发者提供开箱即用的 AI 辅助编程环境。项目通过一行命令的安装脚本，快速部署一整套预配置的开发工具链，让用户无需手动逐一安装和配置各类扩展组件即可获得完整的智能编码体验。该配置包整合了三大类核心资源：17 个插件（plugins）用于扩展编码代理的具体功能能力，18 个全局技能（global skills）为代理提供跨项目通用的知识和处理模式，2 个 MCP（Model Context Protocol）服务器则负责在代理与外部数据源、工具之间建立标准化的上下文桥梁。项目附带教程性质的 README 文档，帮助新手理解每个组件的作用、配置方式以及协同工作原理，降低了 AI 编码代理生态的上手门槛。整体上，该仓库定位为一个可复现、可分享的个人化开发环境模板，适合希望快速搭建 Pi 代理工作流的开发者参考或直接采用。
