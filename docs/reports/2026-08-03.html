Trajex 会话索引器 ⭐ 57

多 Agent 会话统一索引与查询

TypeScriptNode.js 22ElectronSQLite (FTS5)node:sqlitebetter-sqlite3chokidarelectron-vite
Trajex 是一款面向 AI 编程会话的本地索引与浏览工具，衍生自 tommy0103/obelisk 项目。它把散落在本地的 Claude Code、Codex、Kimi Code 与 Pi 等多种 Agent 的 JSONL transcripts 统一索引到同一个 SQLite 数据库（~/.trajex/trajex.sqlite）中，让数万行历史会话可被毫秒级查询。工具由两面组成：CLI 侧提供 trajex 命令与配套 skill，让 coding Agent 能自动编写 JS 查询、通过 search/context/sql 等 API 检索会话、tool calls、subagents 与 workflows，并以自然语言回答；App 侧是 Electron 桌面应用，提供 Sessions 浏览、Memory 管理、Activity 热力图、每周 Recap 卡片与 Settings 配置。索引器支持增量更新，通过 chokidar 监听多个 provider 根目录变化，App 运行时作为 active indexer 独占写权限，CLI 则保持只读，避免跨进程冲突。全文检索基于 SQLite FTS5，CLI 直接使用 Node 22 内置的 node:sqlite 零依赖运行。
在多个 coding Agent 并存的当下，Trajex 用一个本地 SQLite 打通了跨 Provider 的会话历史，同时兼顾 Agent 自动查询与用户可视化浏览两种使用范式，是把 AI 会话历史资产化的实用范例。
