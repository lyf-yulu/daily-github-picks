VoltAgent 是一个由官方开发团队与社区共同维护的开源项目，汇集了 1000 余款可复用的 Agent Skills（智能体技能），旨在为主流 AI 编码助手提供统一、可移植的能力扩展库。项目定位于跨工具的技能生态中枢，所收录的技能兼容 Claude Code、OpenAI Codex、Gemini CLI、Cursor 等多款主流 AI 开发环境，开发者无需为不同工具重复编写提示词或工作流，即可在任意兼容平台上调用同一份技能定义。项目采用精选（curated）策略，对来自官方 DevRel 团队和社区贡献者的技能条目进行分类、审核与整理，覆盖代码生成、调试、测试、重构、文档编写、DevOps、前后端框架适配等多个开发场景。通过统一的技能描述规范，用户可以按需检索、组合并加载技能，快速把资深工程师沉淀的最佳实践引入日常编码工作流。对于希望构建可复用 AI 工作流、比较不同 CLI 代理能力，或在团队内统一 AI 使用规范的开发者与组织而言，VoltAgent 提供了一个开箱即用、社区驱动的技能索引与分发中心，是当前多代理生态下极具参考价值的资源集散地。
在 AI 编码代理工具快速涌现、各家提示词与工作流互不兼容的背景下，VoltAgent 通过统一的技能格式与跨工具兼容策略，为开发者解决了『重复造轮子』和『技能锁定』两大痛点，是当前 Agent Skills 领域规模最大、覆盖最广的社区索引之一，具备成为多代理生态事实标准资源库的潜力。

oa-design 设计语言技能包 ⭐ 116

Open Analytics 设计语言的 Agent 可执行版

ReactTailwind CSS v4motion.devTypeScriptCSS shape() / color-mixNode.js CLI (npx getopen-design)Markdown-based Agent Skill
oa-design 是 Open Analytics 官方开源的设计语言项目，将其仪表盘产品中所有的视觉与交互规范以三种形态一次性打包交付：可供 AI Agent 直接执行的 Skill、经过类型检查的组件配方（recipes），以及 shadcn 风格的 CLI 工具。项目核心理念是让 Claude Code、Cursor 或任意 Agent 都能按照统一规则复现 Open Analytics 的产品观感，一句话概括其风格便是白色表面配连续曲率圆角、静谧灰底、单一墨色与单一弹簧动画。所有色值、圆角、缓动与弹簧常数都直接来自线上产品，并附有推理说明。仓库结构清晰分为 skills/（Agent 技能与十条规则、七种弹簧表、组件配方索引及 _root.css token 块）、components/（含 squircle-card、button、dropdown、tab-bar、modal、multi-step-dialog、skeleton、notice-strip、floating-pill、toast、header-morph、reveal 等类型检查源码）、cli/（npm 包 getopen-design）以及可整体粘贴的 DESIGN-SKILL.md。配方内的代码由 build/sync.mjs 从 components/ 目录同步注入，保证与 npm run typecheck 通过的源码完全一致。它不是运行时组件库或主题包，只输出可移植的 CSS 数值与弹簧常数，可嵌入任何已有设计系统作为补齐。
在 Agent 编码时代，设计一致性往往是 LLM 生成 UI 最难跨越的坎。oa-design 用 Skill + Recipes + CLI 的三合一形态给出了一个可复制的样板：它把一款上线产品的视觉体系逐条拆成 Agent 可执行的规则和可注入的类型安全源码，让 AI 不再只是拼凑 shadcn 组件，而是能按同一套 token、同一组弹簧、同一种连续曲率语言产出稳定观感。对于想让 Claude Code 或 Cursor 生成品牌一致 UI 的团队，它既是范例也是可直接借用的工程结构。

Python 3.9+Python 标准库（无第三方依赖）SQLiteMCP (Model Context Protocol)Claude Code Pluginuv / uvx / pipx
swissdevjobs-cli 是一款零依赖的 Python 命令行工具，聚合了 8 个国家 9 个招聘平台的技术岗位搜索能力，包括瑞士、德国、英国、美加、荷兰、法国的 devitjobs 系列（约 4700 个强制公开薪资的 IT 岗位），以及瑞士全行业的 jobs.ch、jobup.ch（约 5 万条）和新加坡政府 MyCareersFuture 的 IT 岗位（约 9000 条）。核心特性是把薪资作为一等过滤条件（--min-salary），并通过解码 MongoDB ObjectId 还原真实发布时间，避免被平台刷新的假新岗欺骗。工具用本地 SQLite 记录已投递记录，自动去重跨平台重复岗位。除 CLI 外还内置 MCP Server 和 Claude Code 插件，所有命令支持 --json 输出，可被 LLM Agent 直接驱动；同时会检测无法投递的黑洞岗位并给出替代入口。仅使用 Python 标准库，无第三方依赖，Python 3.9+ 即可运行。

store-screenshots 是一款面向 Claude Code 与 OpenAI Codex 的 AI 代理技能（Agent Skill），可将原始应用截图自动转换为 App Store 与 Google Play 上架所需的营销图片。项目通过纯 HTML/CSS 绘制 iPhone、iPad、Galaxy、Fold、Flip 等设备外框，无需外部素材授权；能够解析应用的 colors.xml、.xcassets 及 App Icon 提取真实品牌配色，并提供 Modern/Minimal、Pop、Dark 等预设风格。它会读取每屏内容生成收益导向的营销文案，经用户审阅后再全量渲染；还内置了 adb、simctl、idb、Maestro 等自动化能力，可直接驱动应用完成截图采集并统一状态栏为 9:41 与满电量。最终通过 Headless Chrome 输出并使用 sips 或 ImageMagick 逐像素校验，产出 1320×2868、1284×2778、2064×2752、1080×1920 等各商店严格规格的 PNG 文件，全程本地运行，不上传任何数据。

mediagen ⭐ 56

编码智能体的图像视频生成技能

Node.jsnpmTypeScript/JavaScriptMCP (Model Context Protocol)Google Gemini APIOpenAI APIKie AI API
mediagen 是一款为 Claude Code 等编码智能体（AI Coding Agent）设计的图像与视频生成技能包，通过统一的 CLI 与 MCP 服务器将 Google Gemini、OpenAI 和 Kie AI 三大提供商聚合到同一接口之下。用户只需用自然语言向智能体描述需求，工具即可自动选择合适的提供商与模型（例如 Gemini 支持 21:9 及视频，OpenAI 无法生成 16:9，Kie 聚合约 30 种第三方模型），生成图像或视频，并支持基于已有素材的编辑。项目内置提示词撰写指南，能将模糊描述扩展为包含主体、构图、光线、镜头与材质的完整提示；同时提供符合欧盟 AI 法案的内容标记功能（visible label 与元数据），适用于写实或发布用途。通过 `mediagen init` 交互式向导安全配置 API Key（避免出现在 shell 历史与进程列表中），并支持环境变量、.env 与配置文件三层解析，配合 `doctor` 与 `models` 命令进行密钥探测与提供商优先级检查，实现失败自恢复。基于 Node.js 20.11+ 分发于 npm。
