Agent Council 智能体议会 ⭐ 111

多 AI CLI 协作汇聚多元观点

Node.jsShell (Bash)YAMLClaude Code SkillCodex CLIGemini CLI
Agent Council 是一个面向 Claude Code 与 Codex CLI 的多智能体协作插件（Skill），受 Karpathy 的 LLM Council 项目启发，但改为调用用户本机已安装的 AI 命令行工具（如 Claude Code、Codex CLI、Gemini CLI 等），而不是直连各厂商 API，因此在已有订阅前提下不产生额外调用费用。项目实现了一套三阶段协作流程：首先将用户问题并行分发给配置中列出的所有智能体成员，收集各自的独立回答；随后以格式化视图汇总展示各方观点；最后由宿主 CLI 作为 Chairman（主席）角色对全部意见进行综合，输出最终建议，也可通过配置指定专门的 Chairman 命令在脚本内完成综合。安装方式提供 npx 一键安装与 Claude Code 插件市场两种途径，安装器会自动检测本机可用的 CLI 并生成 council.config.yaml 模板，用户可自由添加成员、图标与颜色。核心执行脚本 council.sh 支持一次性调用与后台作业模式（start/status/wait/results/clean），并针对宿主工具 UI 提供 checklist、JSON 进度等多种输出形式，方便与 Codex 或 Claude 的原生任务面板集成。整体基于 Node.js 与 Shell 实现，强调轻量、可复现、易于自定义。
在 Agent 生态爆发的当下，该项目用极简的 Skill + Shell 方案解决了跨 CLI 多智能体协作的实际痛点，既避开了 MCP 的复杂度，又绕开了 API 计费问题，让订阅用户可以自由组合 Claude、Codex、Gemini 等主流工具进行多视角决策，是一个对个人开发者非常务实的协作范式参考。

Agent Harness 性能优化系统 ⭐ 377 (+377 today)

为AI编码代理注入技能与记忆

Claude CodeOpenAI CodexOpencodeCursorAgent Harness 生态
该项目是一套面向 AI 编码代理（Agent Harness）的性能优化系统，旨在为 Claude Code、Codex、Opencode、Cursor 等主流 AI 编程助手提供统一的能力增强层。项目围绕五大核心维度构建：Skills（技能扩展）、Instincts（直觉决策）、Memory（记忆管理）、Security（安全防护）以及 Research-first Development（研究优先的开发范式），试图弥补当前 AI 编码工具在长期上下文保持、领域知识沉淀和安全边界控制方面的不足。通过将可复用的技能模块、行为直觉和持久化记忆注入到不同厂商的 Agent 中，开发者可以获得跨工具的一致体验，避免在切换 Agent 时重复配置。项目强调 research-first 理念，鼓励代理在动手写代码前先进行充分的上下文调研与方案验证，从而减少幻觉和返工。整体定位偏向元层工具（meta-tooling），并非替代现有 AI 编码助手，而是作为它们的性能与行为治理层存在，服务于对代码质量、安全合规和工程规范有较高要求的团队与个人开发者。由于仓库当前 README 信息较为精简，具体实现细节和技术栈尚待进一步公开。
在 AI 编码助手同质化严重的当下，该项目切入的是一个被忽视但价值极高的中间层：不做新的 Agent，而是为已有 Agent 提供技能、记忆和安全治理。这种元层思路能够沉淀跨工具通用的工程实践，避免开发者被单一厂商锁定，同时把 research-first、安全边界等企业级关注点前置到代理行为层，具备成为团队级 AI 编码基础设施的潜力。

mentor ⭐ 64

为AI编码代理生成会话洞察报告

PythonuvHTMLSVGMarkdown (SKILL.md)skills.sh
mentor 是一个面向 AI 编码代理（Claude Code、Codex 及任何兼容 SKILL.md 格式的代理）的会话洞察技能。它在本地读取用户的 Claude Code 会话记录（~/.claude）与 OpenAI Codex 滚动日志（~/.codex），聚合多次会话数据，生成一份自包含的 HTML 报告，展示用户实际的工作方式：做了什么、时间浪费在哪里、以及具体的改进方案。报告包含八个板块，涵盖工作主题聚类、代理使用方式、成功经验、摩擦点、值得尝试的功能、可复制到 CLAUDE.md 的配置建议、新工作流以及趋势预测。核心价值在于摩擦分析部分，每个问题都对应可执行的修复方案（如 CLAUDE.md 配置、hook 或习惯调整），形成周度反馈闭环。工具由三个 Python 脚本驱动：collect.py 解析会话生成统计包，代理基于摘要撰写分析，render_report.py 合成最终 HTML。所有数据本地处理，不上传，通过 skills.sh 一键安装。

applied-micro-skills 是一个面向应用微观经济学实证研究的技能库，为 Claude Code 与 Codex 两大 AI 编程助手提供 18 个自包含技能模块，覆盖从文献检索、数据获取、LLM 辅助分类、计量估计、表格图形制作到最终交付的完整研究流水线。项目将验证作为核心理念：adversarial-empirical-review 在隔离环境中重跑整个流水线以确保论文中的数字可从原始数据复现；LLM 方法集群包含标注输入一致性检查、金标准边界诊断、活动漂移守门等五个技能，防止分类活动因 provider 端模型变更或标签污染而失效。基础设施层面提供 WRDS 安全登录、pystata 驱动、pyfixest GPU 加速与网格分片、事件研究 CAR 引擎（与 Stata eventstudy2 对齐至浮点精度）。输出层面支持 estout 风格 LaTeX 表格、Stata 风格 matplotlib 图形、引用放置、LaTeX 转 Word、Markdown 转 PDF 等，帮助研究者高效产出发表级成果。

通用版 Fable 5 系统提示词 ⭐ 418

跨模型通用的 Claude 系统提示词精简版

MarkdownPrompt EngineeringLLM System Prompt
本项目是对 Anthropic 公开的 Claude Fable 5 / Mythos 5 系统提示词的厂商中立化改造版本。原始提示词包含大量为 Claude 生产环境定制的基础设施内容，例如 XML 约定、工具接口、产品化行为规则以及内部实现指引，这些内容在迁移到其他前沿大模型时收益有限甚至产生干扰。作者通过系统性过滤，剥离了 Claude 专属实现细节，保留具有跨模型普适价值的行为准则，并使用干净的 Markdown 格式重新组织，使其可以直接投入 Gemini 3.1 Pro、ChatGPT 5.6、DeepSeek、Qwen、Grok、GLM 等主流指令跟随模型使用。仓库提供三档版本：core.md 追求最小 token 占用的核心原则，balanced.md 在体积与覆盖度之间取得平衡（推荐日常使用），complete.md 则保留了几乎全部与厂商无关的行为指引。保留的关键能力包括：理解用户真实意图、诚实处理不确定性、自然清晰的表达、高质量代码生成、带权衡分析的实用建议、回答前的自我校验以及客观纠错等。项目定位并非替代或超越 Anthropic 官方版本，而是提出一个不同的问题：剥离 Claude 专属实现后，哪些行为原则仍具有普适价值。使用者可将其粘贴到 API 的 system 字段，或作为自定义 GPT、Gemini Gems 的指令使用。
在系统提示词工程日益成为核心竞争力的当下，该项目从一份具备工业级打磨的 Claude 提示词中提炼出可跨模型迁移的行为原则，并给出三档 token 预算方案，对于构建多模型 Agent、需要在 Gemini / ChatGPT / 开源模型之间切换的开发者具有直接的复用价值，也为 prompt 减负与蒸馏提供了一个可参考的方法论样本。
