oa-design ⭐ 114

Open Analytics 设计语言的 Agent 技能包

TypeScriptReactTailwind CSS v4motion.devCSS shape() / color-mixNode.js CLI (npx getopen-design)Markdown-based Agent Skill
oa-design 是 Open Analytics（getopen.so）产品设计语言的开源封装，将其仪表盘中经过实战打磨的视觉与动效规范打包成三种形态：可供 AI Agent 直接执行的 Skill、经过类型检查的组件配方（recipes），以及类似 shadcn 风格的 CLI 工具。项目的核心理念是把每一个十六进制色值、弹簧常数、圆角半径和缓动曲线都从已上线的产品中抽取出来，并附上设计推理，让 Claude Code、Cursor 或任何 Agent 都能理解并复现同一套视觉语言。整体风格可用一句话概括：白色表面、连续曲率圆角、静谧灰色舞台、单一墨色、单一弹簧驱动。仓库包含 skills/oa-design 目录下的 Agent Skill（含十条规则、弹簧表和组件索引）、_root.css 令牌块、每个组件一个的 Markdown 配方，以及 components/ 目录下经 TypeScript 类型检查的源码。通过 build/sync.mjs 脚本，源码会被自动注入到配方 MD 与 npm 包中，保证文档与代码严格一致。语言层面涵盖 squircle 卡片系统（CSS shape() 剪裁）、七种弹簧动效词汇、对话框高度编排、Tab Bar 标签遮罩、着陆页玻璃变形、骨架屏模糊入场等标志性动作，还包括布局、通知条、悬浮胶囊、Toast 物理效果与文案语气。运行时零依赖，基于 React + Tailwind v4 + motion 编写，但输出的都是纯 CSS 数值和弹簧常数，可移植到任意技术栈。
这是把生产级设计系统交付给 AI Agent 的一次范式尝试：不再让模型凭感觉猜测色板与动效，而是把已上线产品的每一个数值和背后推理压缩成可执行的 Skill 文件。同时它示范了一种优雅的仓库形态——单一源代码 + 同步脚本，同时产出 CLI、Agent Skill 和文档，避免了传统组件库文档漂移的老问题。对希望搭建自家设计语言 Agent 化的团队而言，是极具参考价值的模板。

Cybermes 是一款面向企业级攻防安全研究的自主智能体框架，聚焦漏洞赏金、红队演练和进攻性安全评估场景。项目基于 Hermes Agent 构建自主推理循环，结合多模型 LLM 编排、专业化推理技能与精选知识库（PayloadsAllTheThings、HackTricks、Claude-BugHunter 等），实现从侦察、攻击面发现、鉴权漏洞挖掘到零误报漏洞验证的端到端自动化。框架内置 50 余个进攻性技能模块，覆盖 Next.js/AI 路由审计、IDOR/BOLA、认证绕过、竞态条件、DOM XSS、SSRF 与注入等常见攻击面。为解决传统扫描器噪音大、上下文膨胀的问题，Cybermes 引入原生 Go 实现的 smart_pipe 与 Markdown MCP 转换器，可将冗长日志压缩 70–85%，显著节约 Token 成本；同时通过确定性 HTTP 证据、状态码校验与独立 Python PoC 脚本组成零误报门禁，仅上报可复现漏洞。项目提供自动化 PDF/HTML 高管报告引擎、后台权限守护进程（POSIX ACL）以及目标隔离的目录结构，支持 Linux、macOS 与 Windows（PowerShell 原生、WSL2、Docker Desktop）三大平台部署，并遵循 AGENTS.md 与 .cursorrules 通用 AI 代理规范。

SetFree ⭐ 56

让编码 CLI 自由连接任意 LLM

GoTOML 配置Shell/PowerShell 安装脚本Mermaid（文档）
SetFree 是 MindsDB 开源的一款轻量级命令行包装工具，旨在解耦编码 CLI（如 Claude Code、Codex、VS Code 中的 Claude 扩展等）与其默认绑定的 LLM 服务商，让开发者可以将喜爱的编码代理指向任意 LLM 网关、企业私有网关或本地代理。使用方式极简，只需在原命令前加上 setfree 前缀（例如 setfree claude），首次运行会交互式引导配置网关，此后保持静默透传所有参数。工具通过适配器模式支持不同 CLI，核心机制是构建环境变量后启动原生 CLI 二进制，本身不代理流量、不修改二进制、不介入认证。配置分离存储于 config.toml 与 credentials.toml（Unix 下 0600 权限），并支持环境变量覆盖，便于 CI/脚本场景。项目使用 Go 编写，单二进制分发，自带每日自动更新（含 checksums 校验），提供 curl/PowerShell 安装脚本。
