APEX 推理芯片 ⭐ 378

位精确验证的开源LLM推理芯片瓦片

SystemVerilog/RTLFPGAINT8 脉动阵列 (MXE)Python/NumPy 黄金模型UVM 验证Qwen2.5 (0.5B/7B)在线 Softmax、RoPE、RMSNorm、SwiGLU
APEX 是一款完全开源、以验证为先的 LLM 推理加速器设计，实现了一个完整的 Transformer 解码器层的 RTL 电路。项目在 FPGA 硬件上实测运行真实的 Qwen2.5-0.5B 模型，实测推理速度 0.56 tok/s，相比初版提升 140 倍。核心模块涵盖注意力计算、KV 缓存压缩、Softmax、RMSNorm、RoPE、SwiGLU 与残差连接，每个 RTL 块都与可执行的 NumPy 黄金模型进行位精确比对，杜绝“近似正确”。架构上采用两个关键押注：其一是将 KV 编解码器放入数据通路内部，键值在生成瞬间被量化压缩、在消费瞬间被解压，通过 TIP 重要性单元自适应分配 KVQ8/KVQ4/KVQ4+离群值等精度层级，让阅读速度不随上下文增长而下降；其二是方法论上坚持 bit-exact 黄金模型验证、变异测试与反造假证据链。设计中一个 INT8 脉动阵列 MXE 被时分复用于解码层的全部七个矩阵任务，量化尺度随张量在同一接缝中流动，使每个作业仅凭描述符即可位精确重放。项目范围诚实限定为“单个瓦片”，不含 DRAM 控制器、PCIe 与 NoC，但架构已按 7B 级模型（head_dim=128）尺寸预留，Qwen2.5-7B 已通过软件验证的黄金流水线。所有性能数据均明确标注为“实测”或“投影”。
这是极少数将“LLM 推理芯片”从口号推进到 bit-exact 验证 + 真机跑通的开源项目：把 KV 压缩从软件层下沉进硅上数据通路是架构上的独立赌注，配合可复现的黄金模型和公开的实测/投影分离数据，对边缘 LLM 加速器设计与开源硬件验证方法学都具有参考价值。

Vibe Coding Toolkit 是一套面向 Claude Code（及部分兼容 OpenAI Codex）的 AI 辅助编程工作流工具包，由巴西开发者 Matheus Gomes 基于真实金融科技（受 NDA 保护）生产项目提炼而来。项目的核心定位不是罗列插件清单，而是提供一条经过实战验证的完整流程：从安装、项目配置（CLAUDE.md、hooks），到头脑风暴与规划，再到多子代理并行编排、多代理代码评审，最后进入受质量门禁保护的提交环节。作者反复强调 Superpowers 插件是整个工具箱最重要的一环，它强制代理先探索意图、再规划、最后写码，避免把大 prompt 一股脑丢进去碰运气。围绕 Superpowers，仓库还提供了子代理波次并行编排协议（在结构层面消除文件冲突与提交竞争）、ESLint/Biome 质量门禁（把 warning 提升为 error 并作为受追踪迁移）、Graphify + Context7 编码前的知识图谱指引、RTK token 代理降本方案、Ponytail/Caveman 人格提示模板，以及基于 Claude 原生记忆和 Obsidian 的跨会话记忆体系。所有内容均以中/葡文档形式沉淀，配合 CLAUDE.md 模板和 /aia-harness:init 快速初始化命令，让开发者能把 AI 代理真正当作团队成员使用，而不是需要保姆的实习生。
这是极少数从真实生产项目（金融科技 NDA 项目）反向抽取并泛化的 AI 编程方法论仓库，而非「看起来很酷」的插件集合。作者明确交代每一项都为解决过至少一次真实痛点而存在，并给出可复制的目录结构、模板与协议。子代理并行编排协议和 lint 质量门禁作为架构边界的做法，在同类第三方合集里几乎看不到，对希望把 Claude Code 从玩具用成生产力工具的团队有直接参考价值。

Awesome DeepSeek Harness 是一份围绕 DeepSeek 官方 Agent 运行时框架 DeepSeek Harness（简称 DSH）构建的社区精选资源列表。DSH 的核心理念是「Model + Harness = Agent」，把大模型的推理能力通过上下文管理、工具调用编排、执行沙箱、反馈循环与会话持久化等机制转化为可实际执行动作的智能体，并采用「一切皆插件」的开放式架构（基于 Cordis 与 TypeScript 实现）。本仓库以 awesome-list 形式，系统性收录了官方项目、Profiles 与 Patch 层、Harness 运行时、安全与权限、会话与记忆管理、成本追踪、IM 桥接、插件市场、可视化、PPT、编码、Agents、自动研究循环、MCP Servers、编排聚合器、UI 客户端以及 Skills 等十余个大类的社区扩展。清单特别强调 DSH 独有的 Profiles 与 Patch 层机制：通过分层叠加 bundle 与 cordis.patch.yml，可在不 fork 代码的情况下，为长时任务、数学推理、幻灯片编辑等场景快速拼装出专用运行时。项目要求收录仓库带上 #dsh GitHub topic 以便社区中心索引，并提供 npx 一键启动 Web UI 与 dsh plugin add 命令行安装体验。
